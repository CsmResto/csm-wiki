Эта страница используется как справочник. Найдите нужный параметр и проверьте, какие данные участвуют в расчете, какую базу расчета можно выбрать, какие операторы доступны и какие ограничения действуют для значения.

## Как устроено правило варианта

Правило определяет, при каких условиях гостю присваивается вариант автотега.

![автотеги](/ru/images/autotags/autotags-create/autotags-create6.png)

[[delimiter rows=1]]

Правило может включать:

- **Параметр** — показатель, который система рассчитывает для гостя.
- **Оператор** — правило сравнения рассчитанного показателя с указанным значением.
- **Сравнить с** — число, диапазон, время, количество дней или среднее значение по базе гостей в зависимости от параметра.
- **База расчета** — данные, на которых рассчитывается параметр: период, последние заказы или вся история.
- **Горизонт расчета** — количество дней или заказов, которые должны участвовать в расчете.
- **Математическая операция** — дополнительная поправка к среднему значению по базе гостей, если она доступна для выбранного параметра.

[[info type=custom color=#E06823]]
Если гостю одновременно подходят несколько вариантов одного автотега, система присваивает первый подходящий вариант с самым высоким приоритетом.
[[/info]]

## База расчета

База и горизонт расчета определяют, какие данные гостя участвуют в правиле. Доступные варианты зависят от выбранного параметра.

- **Период** — используются данные за указанный период. Доступны варианты:
  - `Последние N дней`;
  - `От M до N дней назад`.
- **Заказы** — используются последние `N` чеков гостя.
- **За все время** — используется вся доступная история гостя для выбранного параметра.

Если параметр не использует исторические данные, поле `База расчета` не отображается.

### Период `От M до N дней назад`

Для параметров, поддерживающих расчет по периоду, можно указать скользящий диапазон относительно текущей даты.

- обе границы обязательны;
- диапазон включает обе границы;
- допустимы только целые числа от `1` до `9999`;
- `M ≤ N`;
- `M = N` допустимо;
- если `M > N`, период считается некорректным;
- границы пересчитываются относительно текущей даты при каждом пересчете автотега.

[[info type=custom color=#E06823]]
Для существующих правил с периодом ничего не меняется: они продолжают рассчитываться в режиме `Последние N дней` с ранее сохраненным значением.
[[/info]]

### Ограничения горизонта

- количество дней для режима `Последние N дней` — от `0` до `9999`;
- количество последних заказов — от `0` до `99999`.

[[delimiter rows=1]]

### Какие чеки участвуют в расчете

Для параметров на основе чеков система использует только подходящие записи. В базовом случае чек должен:

- Быть закрытым;
- Иметь положительную сумму;
- Иметь положительную продолжительность;
- Быть привязан к существующему столу.

Для некоторых параметров действуют дополнительные условия.

- Для группы показателей среднего чека требуется не менее 5 подходящих чеков.
- Для `Среднего чека на гостя` и `Среднего чека на гостя в час` количество гостей в чеке должно быть больше нуля.
- Для показателей среднего чека дополнительно указан минимальный размер чека: более 1 000 рублей или более 50 дирхамов.

[[info type=custom color=#E06823]]
Если часть исторических данных не содержит информации, необходимой для конкретного расчета, такие записи не участвуют в выборке. Система использует только данные, по которым правило можно рассчитать полностью.
[[/info]]

## Операторы сравнения

В зависимости от параметра доступны:

- `>` — больше;
- `≥` — больше или равно;
- `<` — меньше;
- `≤` — меньше или равно;
- `=` — равно;
- `≠` — не равно;
- `В диапазоне` — значение находится внутри указанного диапазона.

Для большинства числовых параметров значение сравнения:

- не может быть меньше `0`;
- не может быть больше `999 999 999 999`;
- может быть нецелым, если для конкретного параметра не указано иное.

## Визиты

### Время визита

Параметр определяет, в какое время суток гость обычно находится в заведении. Расчет идет по времени чеков.

- **База расчета:** период, количество заказов, за все время.
- **Оператор:** `В диапазоне`.
- **Значение:** диапазон времени от `00:00` до `23:59`, шаг выбора — 1 час.
- **Особенность диапазона:** начальная граница включается, конечная — не включается.

### Дата последнего визита

Параметр использует локальную дату самого позднего подходящего чека гостя. Расчет идет по чекам.

- **Операторы:** `>`, `≥`, `<`, `≤`, `=`, `≠`, `В диапазоне`.
- **Значение:** количество дней назад.
- **Ограничение значения:** целое число от `0` до `999 999 999 999`.

### Средняя продолжительность визита

Параметр показывает среднюю продолжительность визитов гостя. Расчет идет по чекам.

- **База расчета:** период, количество заказов, за все время.
- **Операторы:** `>`, `≥`, `<`, `≤`, `=`, `≠`, `В диапазоне`.
- **Значение:** число.

## Финансовые показатели

### Средний чек

Параметр показывает среднюю сумму подходящих чеков гостя. Расчет выполняется, если у гостя есть не менее 5 чеков.

Средний чек рассчитывается как сумма подходящих чеков, деленная на их количество.

- **База расчета:** период, количество заказов, за все время.
- **Операторы:** `>`, `≥`, `<`, `≤`, `=`, `≠`, `В диапазоне`.
- **Сравнить с:** число или среднее значение этого параметра по базе гостей.
- **Значение:** число от `0` до `999 999 999 999`; допускаются нецелые значения.

### Средний чек в час

Параметр показывает отношение суммы чеков к общей продолжительности визитов. Расчет выполняется, если у гостя есть не менее 5 чеков.

- **База расчета:** период, количество заказов, за все время.
- **Операторы:** `>`, `≥`, `<`, `≤`, `=`, `≠`, `В диапазоне`.
- **Сравнить с:** число или среднее значение этого параметра по базе гостей.
- **Значение:** число от `0` до `999 999 999 999`; допускаются нецелые значения.

### Средний чек на гостя

Параметр учитывает сумму чека и количество гостей в нем. Расчет выполняется, если у гостя есть не менее 5 чеков. 

Для каждого чека система делит сумму на количество гостей, после чего суммирует полученные значения по выбранной базе.

- **База расчета:** период, количество заказов, за все время.
- **Операторы:** `>`, `≥`, `<`, `≤`, `=`, `≠`, `В диапазоне`.
- **Сравнить с:** число или среднее значение этого параметра по базе гостей.
- **Значение:** число от `0` до `999 999 999 999`; допускаются нецелые значения.

### Средний чек на гостя в час

Параметр одновременно учитывает сумму чека, количество гостей и продолжительность визита. Расчет выполняется, если у гостя есть не менее 5 чеков.

- **База расчета:** период, количество заказов, за все время.
- **Операторы:** `>`, `≥`, `<`, `≤`, `=`, `≠`, `В диапазоне`.
- **Сравнить с:** число или среднее значение этого параметра по базе гостей.
- **Значение:** число от `0` до `999 999 999 999`; допускаются нецелые значения.

### Сумма последнего заказа

Параметр использует сумму самого позднего подходящего чека гостя.

- **База расчета:** отсутствует.
- **Операторы:** `>`, `≥`, `<`, `≤`, `=`, `≠`, `В диапазоне`.
- **Сравнить с:** число или среднее значение этого параметра по базе гостей.
- **Значение:** число от `0` до `999 999 999 999`; допускаются нецелые значения.

### Сумма трат

Параметр показывает общую сумму трат гостя по валидным чекам в выбранной базе расчета.

- **База расчета:** период или за все время.
- **Операторы:** `>`, `≥`, `<`, `≤`, `=`, `≠`, `В диапазоне`.
- **Значение:** число от `0` до `999 999 999 999`; допускаются нецелые значения.

### Количество чеков

Параметр показывает количество валидных чеков гостя в выбранной базе расчета.

- **База расчета:** период или за все время.
- **Операторы:** `>`, `≥`, `<`, `≤`, `=`, `≠`, `В диапазоне`.
- **Значение:** число от `0` до `999 999 999 999`.

### Сравнение со средним по базе гостей

Для параметров `Средний чек`, `Средний чек на гостя`, `Средний чек в час`, `Средний чек на гостя в час` и `Сумма последнего заказа` можно сравнивать значение гостя со средним значением аналогичного параметра по базе гостей.

Для среднего значения задается отдельный горизонт в днях. После расчета к нему можно применить дополнительную математическую операцию:

- прибавить или вычесть число;
- прибавить или вычесть процент от среднего значения.

Допустимое значение математической поправки — от `-999 999 999 999` до `999 999 999 999`; допускаются нецелые значения. Процент не ограничен диапазоном от 0 до 100, поскольку используется как коэффициент.

## Покупки

### Купленные продукты

Параметр позволяет создавать правила на основе продуктов, которые гость приобретал в своих заказах. Можно выбрать родительскую категорию или группу — тогда автоматически учитываются все дочерние продукты.

Система считает количество позиций в подходящих чеках, которые соответствуют выбранным продуктам.

- **База расчета:** период, количество заказов, за все время.
- **Операторы:** `>`, `≥`, `<`, `≤`, `=`, `≠`, `В диапазоне`.
- **Значение:** число.

#### Как считать покупки по последним заказам

Если база расчета — `Заказы`, появляется дополнительное поле `Как считать`:

- **В сумме** — условие проверяется по всей выборке последних заказов целиком. Это значение используется по умолчанию.
- **В каждом заказе** — условие должно выполняться отдельно в каждом заказе из выборки.

Например, для правила `Покупки в категории «Фирменные кальяны» ≥ 1 раз` и последних 3 заказов:

- в режиме `В сумме` достаточно одной подходящей покупки суммарно в трех заказах;
- в режиме `В каждом заказе` подходящая покупка должна присутствовать в каждом из трех заказов.

## Оценки

### Средняя оценка

Параметр рассчитывает среднюю оценку гостя за выбранный период.

Расчет выполняется, если у гостя был хотя бы один чек и он оставил хотя бы одну оценку. Учитываются только ответы, для которых указана локация и включено `Участвует в статистике гостя`.

Если один ответ содержит несколько подходящих оценочных вопросов, система сначала рассчитывает среднюю оценку внутри ответа. После этого рассчитывается среднее по всем подходящим ответам.

- **База расчета:** период или за все время.
- **Операторы:** `>`, `≥`, `<`, `≤`, `=`, `≠`, `В диапазоне`.
- **Значение:** число от `0` до `999 999 999 999`.

### Последняя оценка

Параметр использует оценку из самого позднего подходящего ответа гостя. Расчет выполняется, если у гостя был хотя бы один чек. Применяются те же требования к ответам, что и для параметра `Средняя оценка`.

- **Операторы:** `>`, `≥`, `<`, `≤`, `=`, `≠`, `В диапазоне`.
- **Значение:** число от `0` до `999 999 999 999`.

[[delimiter rows=1]]

## Бронирования

### Процент отмененных бронирований

Параметр показывает долю отмененных бронирований гостя. Расчет выполняется, если у гостя было хотя бы одно бронирование.

- **База расчета:** период или за все время.
- **Операторы:** `>`, `≥`, `<`, `≤`, `=`, `≠`, `В диапазоне`.
- **Значение:** число от `0` до `100`.

[[delimiter rows=1]]

## События

### День рождения

Параметр позволяет создавать правила относительно даты рождения гостя. Система сравнивает календарные даты: часы и минуты не учитываются. Разница рассчитывается в целых календарных днях.

- **Операторы:** `>`, `≥`, `<`, `≤`, `=`, `≠`, `В диапазоне`.
- **Сравнить с:** количество дней назад или количество дней вперед.
- **Значение:** целое число от `0` до `365`.

[[delimiter rows=1]]

[[info type=custom color=#E06823]]
Если данных недостаточно для расчета параметра, он не рассчитывается. Если гостю ранее был присвоен вариант этого автотега, старый вариант удаляется. Записи с неполными данными, по которым формулу невозможно рассчитать полностью, не участвуют в выборке.
[[/info]]

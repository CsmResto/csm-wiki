Чтобы создать нового гостя:

1. Перейдите в раздел **Маркетинг** → **Гости**
2. Нажмите **Создать**
3. Заполните данные гостя
4. Нажмите **Создать**


![создание гостя](/ru/images/guests/guest-create.png)

[[delimiter rows=1]]


Обязательные поля:

✔ **Имя**  
✔ **Пол**  
✔ **Номер телефона** или **номер карты** — необходимо заполнить одно из этих полей 

Также можно указать:

✔ **Аватар**  
✔ **Фамилия**  
✔ **Дата рождения**  
✔ **Email**  
✔ **Telegram**  

По умолчанию гость идентифицируется по номеру телефона. Чтобы использовать для идентификации номер карты, нажмите **Номер карты**, после чего введите её номер.

При создании гостя можно указать только один номер телефона. Дополнительный номер можно добавить после создания гостя при редактировании его данных.



## Редактирование гостя

Чтобы изменить данные гостя, откройте его карточку и нажмите **Редактировать**.

Внесите необходимые изменения и нажмите **Сохранить**.

При редактировании гостя можно добавить дополнительный номер телефона. Один из номеров должен быть основным — он используется для поиска гостя по номеру телефона. При необходимости дополнительный номер можно назначить основным.

При изменении номера система проверяет, используется ли этот номер в другом профиле гостя. Если номер уже используется, появится предупреждение. При подтверждении изменений профиль гостя, которому ранее принадлежал этот номер, будет деактивирован.


![проверка номера, дубль](/ru/images/guests/change-number.png)

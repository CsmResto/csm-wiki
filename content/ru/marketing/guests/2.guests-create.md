Чтобы создать нового гостя:

1. Перейдите в раздел **Маркетинг** → **Гости**
2. Нажмите **Создать**
3. Заполните данные гостя
4. Нажмите **Создать**


![создание гостя](/ru/images/guests/guest-create.png)

**2. Фамилия**

**6. Telegram**  
**7. Номер телефона/Номер карты**  

По умолчанию гость идентифицируется по номеру телефона. Чтобы использовать для идентификации номер карты, нажмите **Номер карты**, после чего введите её номер.

Если введен номер карты, то добавление номера телефона невозможно.



## Редактирование гостя

Чтобы перейти к редактированию гостя, используйте один из способов:

- Откройте карточку гостя, нажмите кнопку с двоеточием и выберите **Редактировать**
- В таблице гостей нажмите правой кнопкой мыши на нужного гостя и в контекстном меню выберите **Редактировать**

Внесите необходимые изменения и нажмите **Сохранить**.

![Кнопка с 2 точками](/ru/images/guests/doubledots.png)

### Номера телефона

В профиле гостя можно хранить несколько номеров телефона. Номера можно изменять, а один из них назначить основным для коммуникации с гостем.

[[info type=custom color=#E06823]]
Номер телефона, связанный с картой лояльности, изменить невозможно.
[[/info]]

При добавлении нового номера система проверяет, используется ли он в другом профиле гостя. Если номер уже используется, появится предупреждение. При подтверждении профиль гостя, которому ранее принадлежал этот номер, будет деактивирован.

![проверка номера, дубль](/ru/images/guests/already-in-use.png)

[[delimiter rows=1]]

**Если гость меняет номер телефона и хочет сохранить бонусные баллы и уровень лояльности:**

1. Добавьте новый номер телефона в профиль гостя как дополнительный
2. Попросите гостя зарегистрироваться в системе лояльности с новым номером
3. После регистрации назначьте новый номер основным

Бонусные баллы и уровень лояльности автоматически синхронизируются с новой картой.

**Если гость уже зарегистрировался в системе лояльности с новым номером:**

В этом случае в системе может появиться второй профиль гостя.

Чтобы объединить данные в одном профиле:

1. Откройте профиль гостя со старым номером телефона
2. Добавьте новый номер как дополнительный
3. Подтвердите деактивацию второго профиля в появившемся предупреждении
4. Назначьте новый номер основным

В результате останется один активный профиль гостя, а бонусные баллы и уровень лояльности будут синхронизированы.





### Деактивированный гость

Профиль гостя деактивируется, если его номер телефона добавлен в другой профиль. В этом случае номер телефона будет связан с новым профилем, а бонусные баллы и уровень лояльности синхронизируются с новой картой.

После деактивации профиль остается доступным для просмотра, но его данные нельзя редактировать. Деактивированный гость не участвует в расчете RFM.

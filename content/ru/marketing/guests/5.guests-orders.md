Вкладка **Заказы** содержит список всех заказов, связанных с выбранным гостем.

![страница заказов](/ru/images/guests/orders.png)

[[delimiter rows=1]]

### Таблица заказов

![Column wizard](/ru/images/guests/orders-column.png)

[[delimiter rows=1]]

В таблице отображается информация о заказах выбранного гостя.

Для изменения набора отображаемых столбцов нажмите кнопку настройки таблицы в правом верхнем углу.

В открывшейся панели можно:

✔ выбрать отображаемые столбцы  
✔ закрепить нужные столбцы  
✔ вернуть настройки по умолчанию с помощью команды **Сбросить к начальным значениям**

> **Примечание.** Настройки таблицы сохраняются после обновления страницы и при переходе между карточками гостей. После выхода из системы настройки сбрасываются.





### Просмотр заказа

![детали заказа](/ru/images/guests/order-details.png)

[[delimiter rows=1]]

Нажмите на строку в таблице.

Откроется окно с деталями заказа, в котором можно просмотреть его состав.



### Сводка

![Сумма чеков](/ru/images/guests/orders-total.png) 

[[delimiter rows=1]]

Нажмите кнопку **Сводка** в нижней части окна.

Отобразится сводная информация о сумме заказов, соответствующих выбранным фильтрам.

> **Примечание.** В расчет включаются все заказы, соответствующие выбранным фильтрам, включая записи на других страницах таблицы.




### Фильтрация данных



![Фильтр заказов](/ru/images/guests/orders-filter.png) 

 [[delimiter rows=1]]

 Выберите нужную локацию в списке, чтобы отобразить только связанные с ней заказы.

Для изменения периода отображения выберите нужный диапазон дат.

При необходимости нажмите **Фильтры**, чтобы задать дополнительные условия фильтрации.

После выбора необходимых значений нажмите **Применить**.

Примененные фильтры отображаются над таблицей. Для удаления отдельного фильтра нажмите **×** рядом с его названием. Чтобы сбросить все фильтры, нажмите **Очистить фильтры**.

> **Примечание.** Выбранные фильтры сохраняются после обновления страницы и при переходе между карточками гостей. После выхода из системы фильтры сбрасываются.

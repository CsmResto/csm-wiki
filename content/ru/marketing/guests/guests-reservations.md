Вкладка **Бронирования** содержит список всех бронирований, связанных с выбранным гостем. Здесь можно просмотреть историю бронирований, включая активные, завершенные и отмененные бронирования.

## Фильтрация данных

Для отображения бронирований определенной локации выберите нужное значение в списке локаций.

Для изменения периода отображения выберите нужный диапазон дат.

Для применения дополнительных условий нажмите **Фильтры**.

В открывшейся панели можно отфильтровать бронирования по следующим параметрам:

✔️ статус  
✔️ причина отмены  
✔️ продолжительность  
✔️ депозит  
✔️ стол  
✔️ количество гостей  
✔️ номер бронирования  
✔️ источник бронирования  
✔️ сотрудник, создавший бронирование

После выбора необходимых значений нажмите **Применить**.

Примененные фильтры отображаются над таблицей. Для удаления отдельного фильтра нажмите **×** рядом с его названием. Чтобы сбросить все фильтры, нажмите **Очистить фильтры**.

> [!NOTE]
> Выбранные значения фильтров сохраняются после обновления страницы и при переходе между карточками гостей. После выхода из системы фильтры сбрасываются.

## Таблица бронирований

В таблице отображается информация о бронированиях выбранного гостя.

Для изменения набора отображаемых столбцов нажмите кнопку настройки таблицы в правом верхнем углу.

В открывшейся панели можно:

- выбрать отображаемые столбцы
- закрепить нужные столбцы
- вернуть настройки по умолчанию с помощью команды **Сбросить к начальным значениям**

> [!NOTE]
> Настройки таблицы сохраняются после обновления страницы и при переходе между карточками гостей. После выхода из системы настройки сбрасываются.

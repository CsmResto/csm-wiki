Вкладка **Бронирования** содержит список всех бронирований, связанных с выбранным гостем. Здесь можно просмотреть историю бронирований, включая активные, завершенные и отмененные бронирования.

![Список бронирований](/ru/images/guests/reservations.png) 

[[delimiter rows=1]]

### Таблица бронирований

![Выбор столбцов](/ru/images/guests/reservations-column.png)

[[delimiter rows=1]]

В таблице отображается информация о бронированиях выбранного гостя.

Для изменения набора отображаемых столбцов нажмите кнопку настройки таблицы в правом верхнем углу.

В открывшейся панели можно:

✔ Выбрать отображаемые столбцы   
✔ Закрепить нужные столбцы    
✔ Вернуть настройки по умолчанию с помощью команды **Сбросить к начальным значениям** 



[[delimiter rows=1]]

> **Примечание.** Настройки таблицы сохраняются после обновления страницы и при переходе между карточками гостей. После выхода из системы настройки сбрасываются.

### Сводка

![брони сводка](/ru/images/guests/reservations-total.png)

[[delimiter rows=1]]

Нажмите кнопку **Сводка** в нижней части окна.

Отобразится сводная информация по бронированиям:

✔ количество гостей  
✔ количество бронирований  
✔ распределение бронирований по статусам




> **Примечание.** Сводка рассчитывается по всем бронированиям, соответствующим выбранным фильтрам, включая записи на других страницах таблицы.

### Фильтрация данных

![Заказы с фильтрами](/ru/images/guests/filter-res.png) 

[[delimiter rows=1]]

Выберите нужную локацию в списке, чтобы отобразить только связанные с ней заказы.

Для изменения периода отображения выберите нужный диапазон дат.

При необходимости нажмите **Фильтры**, чтобы задать дополнительные условия фильтрации.

После выбора необходимых значений нажмите **Применить**.

Примененные фильтры отображаются над таблицей. Для удаления отдельного фильтра нажмите **×** рядом с его названием. Чтобы сбросить все фильтры, нажмите **Очистить фильтры**.



> **Примечание.** Выбранные значения фильтров сохраняются после обновления страницы и при переходе между карточками гостей. После выхода из системы фильтры сбрасываются.

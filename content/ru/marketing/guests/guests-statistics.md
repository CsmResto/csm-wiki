## Статистика

При открытии карточки гостя по умолчанию отображается вкладка **Статистика**. На ней собрана информация, позволяющая оценить активность гостя, историю посещений и предпочтения гостя. Данные представлены в виде показателей и графиков.

На вкладке отображаются:

✔ Автотеги гостя  
✔ Статистика посещений  
✔ Средний чек на заказ  
✔ Средний чек на гостя  
✔ Средний размер компании  
✔ Среднее количество заказов в месяц  
✔ Ключевые показатели  
✔ Динамика расходов  
✔ Топ категорий  
✔ Топ продуктов  
✔ Время посещения



### Фильтрация данных

Для просмотра статистики по определенной локации или группе локаций выберите нужное значение в раскрывающемся списке локаций.

Для изменения периода расчета статистики выберите нужный период в раскрывающемся списке периода.

После изменения выбранных значений все показатели и графики автоматически пересчитываются.

> **Примечание.** Виджет **«Среднее количество заказов в месяц»** использует собственный выбор периода и не зависит от общего периода страницы.

### **Посещения**

Виджет отображает информацию о посещениях гостя.

Данные рассчитываются на основе закрытых чеков и отмененных бронирований.

Отображаются:

✔ Общее количество посещений  
✔ Количество отмененных бронирований  
✔ Дата последнего визита  
✔ Доля посещений и отмен в процентах  

### **Средний чек на заказ**

Отображает среднюю стоимость одного заказа гостя.

Расчет выполняется на основе закрытых чеков в выбранных локациях за выбранный период.

График отображает изменение среднего чека по мере совершения заказов.

### **Средний чек на гостя**

Отображает среднюю сумму, потраченную одним гостем за посещение.

Расчет выполняется на основе закрытых чеков в выбранных локациях за выбранный период.

Средний чек рассчитывается путем деления общей суммы чеков на общее количество гостей, указанных в этих чеках.

### **Средний размер компании**

Отображает среднее количество гостей в одном посещении.

Расчет выполняется на основе закрытых чеков в выбранных локациях за выбранный период.

График отображает изменение среднего размера компании по мере совершения заказов.


### **Среднее количество заказов в месяц**

Отображает среднее количество заказов гостя за месяц.

Расчет выполняется на основе закрытых чеков в выбранных локациях.

Для виджета используется собственный выбор периода, независимый от общего периода страницы.

График отображает:

- сплошной линией — данные выбранного периода;
- пунктирной линией — данные предыдущего аналогичного периода.


> **Примечание.** Для расчета используются полные календарные периоды. Например, значение **«Последний месяц»** означает последний полный календарный месяц, а не последние 30 дней.

### **Ключевые показатели**

Отображает основные показатели гостя за выбранный период.

Расчет выполняется на основе закрытых чеков в выбранных локациях за выбранный период.

Отображаются:

| Показатель | Описание |
|------------|----------|
| **Сумма оплат** | Общая сумма оплат по всем чекам гостя |
| **Скидка** | Общая сумма скидок по всем чекам гостя |
| **Количество чеков** | Общее количество чеков гостя |
| **Последний чек** | Сумма последнего чека гостя |
| **Средний чек** | Средняя стоимость одного заказа гостя |
| **Средний чек за час** | Отношение общей суммы оплат к общей продолжительности визитов |
| **Среднее время** | Средняя продолжительность визита |
| **Любимая локация** | Локация, которую гость посещал чаще всего |


**Радиальная диаграмма** отображает относительные значения следующих показателей по сравнению с другими гостями выбранных локаций:

- сумма оплат
- скидка
- средний чек
- средний чек за час
- среднее время посещения

При наведении курсора на точку диаграммы отображается положение гостя относительно других гостей. Например: **«Среднее время у гостя больше, чем у 49% гостей»**.

Значение зависит от выбранного периода и пересчитывается при его изменении.


[[info type=custom color=#E06823]]
 Для показателя «Средний чек за час» учитываются только чеки, продолжительность которых составляет не менее 30 минут или сумма чека составляет не менее 1000 ₽. 
 [[/info]]

### **Всего заплачено**

Отображает суммы чеков гостя в хронологическом порядке за выбранный период.

Расчет выполняется на основе закрытых чеков в выбранных локациях за выбранный период.

График отображает:

- по оси X — последовательность чеков
- по оси Y — сумму каждого чека

В режиме **Последние 30 чеков** на графике отображаются точки отдельных чеков. При наведении курсора на точку отображается:

✔ Локация  
✔ Дата чека  
✔ Время начала и окончания визита  
✔ Продолжительность визита  
✔ Итоговая сумма чека  

При нажатии на точку открываются детали заказа.


### **Топ категорий**

Отображает три категории товаров с наибольшей суммой продаж в выбранных локациях за выбранный период.

Для каждой категории отображаются:

✔ название категории  
✔ общая сумма продаж  
✔ количество проданных позиций  

> **Примечание.**   
В расчет включаются только те категории, для которых в разделе **Меню** включена опция **«Статистика гостя»**.

График отображает:

- по оси X — последовательность чеков
- по оси Y — сумму продаж категории в каждом чеке

### **Топ продуктов**

Отображает пять продуктов с наибольшей суммой продаж в выбранных локациях за выбранный период.

Для каждого продукта отображаются:

✔ название продукта  
✔ общая сумма продаж  
✔ количество проданных позиций  
✔ модификаторы  


При наведении курсора на модификаторы отображается список всех модификаторов и их количество.

### **Время посещения**

Отображает время начала и окончания визитов гостя за выбранный период.

Расчет выполняется на основе закрытых чеков в выбранных локациях за выбранный период.

График отображает:

- по оси X — последовательность чеков
- по оси Y — время суток
- время начала и окончания каждого визита
- продолжительность визита, выделенную областью между линиями

В режиме **Последние 30 чеков** при наведении курсора на визит отображается:

✔ локация  
✔ дата визита  
✔ время начала и окончания  
✔ продолжительность визита  
✔ сумма чека  

При нажатии на отметку визита открывается карточка с деталями заказа.

Раздел **Группы локаций** позволяет объединять несколько локаций в группы для настройки доступа пользователей к базе гостей.




![location groups](/ru/images/location-groups/location-groups.png) 

[[delimiter rows=1]]

Для каждой группы можно определить состав локаций и выбрать тип доступа к гостевой базе. Это позволяет предоставлять пользователям доступ как ко всей базе гостей, так и только к данным выбранной группы локаций.

[[info type=custom color=#E06823]]
 Группы локаций могут объединять рестораны по любому принципу: по региону, бренду, формату, подразделению или другому признаку.

 При формировании группы необходимо учитывать, что пользователь, имеющий доступ хотя бы к одной локации группы, автоматически получает доступ ко всем локациям, входящим в эту группу.
[[/info]]



> **Пример**
>
> В группу **«Москва»** входят несколько ресторанов сети. После объединения их в группу сотрудники каждого из этих ресторанов смогут работать с общей базой гостей группы **«Москва»**, независимо от того, в каком из ресторанов группы гость был ранее.




## Создание группы локаций

Чтобы создать группу локаций, нажмите **Создать**, заполните необходимые поля и нажмите **Создать**.

![создание группы](/ru/images/location-groups/group-create2.png) 

[[delimiter rows=1]]



- **Название.** Введите уникальное название группы.

- **Описание.** При необходимости укажите описание группы, чтобы обозначить ее назначение или особенности использования.

- **Локации.** Выберите одну или несколько локаций, которые необходимо включить в группу.

- **Тип доступа группы.** Выберите тип доступа к базе гостей:

  **✔ Вся база** — пользователи группы получают доступ ко всей базе гостей сети.

  **✔ База группы** — пользователи группы получают доступ только к гостям, имеющим активность в локациях этой группы.

### Поиск

Для поиска группы используйте строку поиска над таблицей.

Поиск выполняется по названию группы и становится доступен после ввода не менее двух символов.

### Таблица групп локаций

![Column wizard](/ru/images/location-groups/group-column.png)

[[delimiter rows=1]]

Для изменения набора отображаемых столбцов нажмите кнопку настройки таблицы в правом верхнем углу.

В открывшейся панели можно:

✔ выбрать отображаемые столбцы  
✔ закрепить нужные столбцы  
✔ вернуть настройки по умолчанию с помощью команды **Сбросить к начальным значениям**

> **Примечание.** Настройки таблицы сохраняются после обновления страницы. После выхода из системы настройки сбрасываются.

### Фильтрация данных

![фильтр](/ru/images/location-groups/group-filter.png) 

[[delimiter rows=1]]

При необходимости нажмите **Фильтры**, чтобы задать дополнительные условия фильтрации.

После выбора необходимых значений нажмите **Применить**.

Примененные фильтры отображаются над таблицей. Для удаления отдельного фильтра нажмите **×** рядом с его названием. Чтобы сбросить все фильтры, нажмите **Очистить фильтры**.

> **Примечание.** Настройки фильтрации сохраняются после обновления страницы. После выхода из системы настройки сбрасываются.

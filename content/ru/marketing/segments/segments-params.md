## Как устроено условие

Условия определяют, какие гости попадут в сегмент.

![Сегменты](/ru/images/segments/segments-params.png)

[[delimiter rows=1]]

Условие может включать:

- **Условие** — параметр гостя или его активности, который система проверяет.
- **База расчета** — дополнительный диапазон данных, на котором рассчитывается условие. В зависимости от параметра база расчета может отсутствовать или задаваться через период, количество чеков либо один из этих вариантов.
- **Оператор** — правило сравнения рассчитанного значения с указанным вами значением.
- **Значение** — число, диапазон, дата, элемент списка, набор тегов или текст в зависимости от выбранного условия.

## База расчета

**База и горизонт расчета** определяют, ĸаĸие данные гостя участвуют в правиле. Для части условий необходимо определить, за какой объем данных выполнять расчет. Доступные варианты зависят от условия и типа сегмента.

**Доступные варианты зависят от выбранного типа сегмента:**

- **Период** — используются данные за последние `N` ĸалендарных дней.
    - **Для динамического:** Количество дней до текущей даты или `За все время`
    - **Для статического:** Конкретный период или `За все время`
- **Заĸазы** — используются последние `N` чеĸов гостя.
    - **Для динамического:** Количество последних чеков или `За все время`
    - **Для статического:** Количество чеков, `За все время` или дадта, до которой учитываются чеки
- **За все время** — используется вся доступная история гостя для выбранного условия.

[[info type=custom color=#E06823]]
База расчета отображается только для условий, которым она требуется. Для условий без базы расчета дополнительные параметры периода или чеков не отображаются.
[[/info]]

## Операторы сравнения

Набор операторов зависит от выбранного условия. В конструкторе могут использоваться:

- `>` — больше.
- `≥` — больше или равно.
- `<` — меньше.
- `≤` — меньше или равно.
- `=` — равно выбранному или указанному значению.
- `≠` — не равно выбранному или указанному значению.
- **В диапазоне** — значение находится внутри заданного диапазона.
- **Вне диапазона** — значение находится вне заданного диапазона.
- **До** — дата раньше указанной даты.
- **После** — дата позже указанной даты.
- **Период** — дата попадает в указанный период.
- **Включая** — текст содержит указанные ключевые слова.
- **Не включая** — текст не содержит указанные ключевые слова.
- **Точное совпадение** — текст полностью совпадает с указанным значением.
- **Не пустое** — поле содержит значение.
- **Пустое** — поле не заполнено.

## Особенности расчета параметров

### Какие чеки участвуют в расчете

Для условий на основе чеков система использует только подходящие записи. В базовом случае чек должен:

- Быть закрытым;
- Иметь положительную сумму;
- Иметь положительную продолжительность;
- Быть привязан к существующему столу.

Для некоторых условий действуют дополнительные требования:

- Для группы показателей среднего чека требуется не менее 5 подходящих чеков.
- Для `Среднего чека на гостя` и `Среднего чека на гостя в час` количество гостей в чеке должно быть больше нуля.

[[info type=custom color=#E06823]]
Если часть исторических данных не содержит информации, необходимой для конкретного расчета, такие записи не участвуют в выборке. Система использует только данные, по которым правило можно рассчитать полностью.
[[/info]]

### Любимая локация

Рассчитывается по чекам, не по визитам гостя.

### Последний визит \  Время визита

Для правила по времени визита система анализирует, сколько времени каждый подходящий визит находился внутри выбранного диапазона и вне его, после чего сравнивает средние значения. Для этого параметра используются локальные даты и время локации.
В расчет входят гости как минимум с одним посещением.

### Ручные теги
Учитывается дата выдачи тега. Можно взять расчет за определенный период, тогда в списке гостей не выдаст тех, у кого он есть сейчас, но был выдан в другую дату. Чтобы получить тех, у кого тег назначен сейчас, выбирайте горизонт `За все время`.

### Оценки

В расчет оценок включаются только ответы, для которых:

- Указана локация;
- Оценка получена из вопроса с включенной настройкой `Include in Guest Statistics`.

Если один ответ содержит несколько таких оценочных вопросов, сначала система рассчитывает среднюю оценку внутри ответа. Для `Средней оценки` затем рассчитывается среднее по всем подходящим ответам. Для `Последней оценки` используется самый поздний подходящий ответ.

### День рождения

Количество дней до или после дня рождения рассчитывается по календарным датам. Время суток не влияет на количество дней.

## Купленные продукты

Условие позволяет выбрать товар через двухуровневый список: **Категория -> Блюдо в категории**, после чего система сравнивает количество выбранных позиций в чеках гостя.

- **База расчета:** период или количество чеков, за все время.
- **Операторы:** `>`, `≥`, `<`, `≤`, `=`, `≠`, **В диапазоне**, **Вне диапазона**.
- **Значение:** количество позиций, целое число от `0` до `999 999 999`.

## Автотеги

Условие использует двухуровневый выбор: **Группа -> Тег в группе**. Набор условий соответствует набору групп автотегов.

- **База расчета:** период (позволяет фильтровать гостей по периоду, когда автотег был назначен), за все время.
- **Операторы:** `=`, `≠`.
- **Значение:** выбранный автотег.


[[delimiter rows=1]]

## Ручные теги

Условие использует двухуровневый выбор: **Группа -> тег в группе**. Набор условий соответствует набору групп ручных тегов.

- **База расчета:** период (позволяет фильтровать гостей по периоду, когда автотег был назначен), за все время.
- **Операторы:** `=`, `≠`.
- **Значение:** выбранный ручной тег.

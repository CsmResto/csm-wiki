**Сегменты гостей** позволяют объединять гостей по заданным признакам и использовать полученные группы в рассылках и аналитике.

В модуле доступны два типа сегментов:

- **Статичный** — фиксирует список гостей на момент создания сегмента.
- **Динамический** — формирует список гостей по заданным условиям и позволяет пересчитывать его по актуальным данным.

**Статичные и динамические** сегменты отображаются на отдельных вкладках. На каждой вкладке можно найти нужный сегмент, открыть его, создать копию или удалить сегмент при наличии соответствующих прав.

[[info type=custom color=#E06823]]
Тип сегмента выбирается при создании. После сохранения изменить тип существующего сегмента нельзя.
[[/info]]

### Данные в списке

Для каждого сегмента отображаются:

- Название
- Локации
- Количество гостей, подходящих под критерии сегмента
- Автор и дата создания
- Автор и дата последнего обновления
- Описание

По умолчанию **новые сегменты отображаются выше** старых. Для количества гостей, даты создания и даты последнего обновления доступна сортировка.

### Поиск и фильтры

![Сегменты](/ru/images/segments/segments-info2.png)

[[delimiter rows=1]]

**Поиск** сегментов доступен по названию.

**Фильтрация** доступна по Локациям, Количеству гостей, Автору и дате создания, Автоу и дате последнего обновления, описанию.

[[info type=custom color=#E06823]]
При выборе локаций доступны только локации, открытые для гостей.
[[/info]]

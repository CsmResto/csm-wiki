Ручные теги используются в нескольких разделах системы:

✔ **Бронирования** — отображаются в карточке гостя, на таймлайне бронирований и на столах флорплана. Ручные теги можно добавлять и удалять непосредственно из бронирования

✔ **Гости** — отображаются в списке гостей и в карточке гостя, где их также можно назначать и удалять

✔ **Сегменты гостей** — используются как один из фильтров при создании сегментов


## Список групп ручных тегов

В списке групп ручных тегов отображаются созданные группы и их основные параметры.

Для поиска группы используйте строку поиска в верхней части страницы. Поиск выполняется по названию группы.

![список групп ручных тегов](/ru/images/manual-tags/tags-list.png)

[[delimiter rows=1]]







## Назначение ручных тегов гостям

Назначить ручные теги можно:

✔ из карточки гостя

✔ из системы бронирования

✔ из Приложения официанта

После назначения тег отображается во всех разделах системы, где используются ручные теги.



## Таблица с группами ручных тегов

![Column wizard](/ru/images/manual-tags/tags-column.png)

[[delimiter rows=1]]


Для изменения набора отображаемых столбцов нажмите кнопку настройки таблицы в правом верхнем углу.

В открывшейся панели можно:

✔ выбрать отображаемые столбцы  
✔ закрепить нужные столбцы  
✔ вернуть настройки по умолчанию с помощью команды **Сбросить к начальным значениям**

> **Примечание.** Настройки таблицы сохраняются после обновления страницы и при переходе между карточками гостей. После выхода из системы настройки сбрасываются.



## Фильтрация данных

![filter](/ru/images/manual-tags/tags-filter.png)

[[delimiter rows=1]]

Для быстрого поиска нужной группы используйте строку поиска и фильтры над таблицей.

Доступна фильтрация по следующим параметрам:

✔ Автор  
✔ Дата создания  
✔ Доступна в Приложении официанта  
✔ Отображение в бронировании  
✔ Последнее обновление  
✔ Редактирование в бронировании

## Что такое конвертер выписок
Конвертер выписок — это инструмент для подготовки банковских выписок к импорту в Транзакции.
Он автоматически собирает данные из выписок, приводит под требования к импорту, позволяет указать категории, а также при наличии категорий контрагентов - находит контрагента по ИНН и автоматом проставляет нужную категорию.

**[Ссылка на Конвертер](https://bank-parser.cosmosresto.ru/)**

Инструмент автоматически:

- распознаёт структуру банковской выписки;
- преобразует операции в единый формат;
- помогает назначать категории;
- поддерживает [автоматическую категоризацию по ИНН](#auto-ancor);
- позволяет вручную редактировать категории перед экспортом.

## Работа с конвертером

![receipt_parser-1](/ru/images/transactions/receipt_parser/receipt_parser-1.jpg)

### 1. Выберите банк

Перед загрузкой выписки выберите банк, из которого был экспортирован CSV-файл.

Доступные варианты:

- Альфа
- ВТБ
- Сбер

### 2. Загрузите банковскую выписку

Требования к файлу:

- формат файла — CSV;
- загружается один файл за раз;
- структура файла должна соответствовать выбранному банку.

[[info type=custom color=#E06823]]
После загрузки система автоматически проверяет структуру файла. Если выписка не соответствует выбранному банку, появится сообщение об ошибке.
[[/info]]

### 3. Загрузите категории (необязательно)

Вы можете дополнительно загрузить CSV-файл с категориями.

Файл категорий можно скачать в разделе: `COSMOS → Финансы → Категории → Экспорт таблицы`

![receipt_parser-2](/ru/images/transactions/receipt_parser/receipt_parser-2.jpg)

[[delimiter rows=1]]

[[info type=custom color=#E06823]]
После загрузки категории становятся доступны для выбора и редактирования в таблице транзакций.
[[/info]]

### 4. Настройте автоматическую категоризацию по ИНН {#auto-ancor}

Конвертер поддерживает автоматическое назначение категорий по ИНН контрагента.

Правила можно:

- настроить вручную;
- загрузить CSV-файлом по шаблону.

Шаблон файла можно скачать в разделе настроек автокатегоризации.

![receipt_parser-3](/ru/images/transactions/receipt_parser/receipt_parser-3.jpg)

[[delimiter rows=1]]

[[info type=custom color=#E06823]]
Правила категорий и автокатегоризации сохраняются в браузере и доступны при следующих загрузках выписок.
[[/info]]

### 5. Проверьте транзакции


После загрузки необходимых файлов нажмите кнопку `Проверить и подготовить файл`. Система обработает выписку и отобразит список транзакций для проверки и редактирования.

Чтобы изменить транзакцию, нажмите на значок карандаша.

![receipt_parser-4](/ru/images/transactions/receipt_parser/receipt_parser-4.jpg)

[[delimiter rows=1]]

[[info type=custom color=#E06823]]
Доступно массовое редактирование и фильтр по незаполненным категориям.
[[/info]]

Для каждой операции можно:
- просмотреть сумму;
- проверить дату;
- посмотреть комментарий;
- изменить категорию вручную.



Если категория не была определена автоматически, поле останется пустым.


### Шаг 6. Скачайте готовый CSV

После проверки данных скачайте подготовленный CSV-файл. Полученный файл можно импортировать в разделе `Транзакции`.

**Особенности выходного файла:**

- списания выгружаются с отрицательной суммой;
- поступления — с положительной;
- время транзакции по умолчанию устанавливается как `12:00`.

При необходимости время можно изменить вручную после скачивания файла.

ℹ️ **Экспорт категорий**

Экспорт позволяет выгрузить список всех категорий вместе с их ID.

Полученный файл можно использовать как справочник при подготовке файлов для импорта транзакций, когда необходимо вручную указать ID категории.

---

## Как выполнить экспорт

1. Откройте раздел **Финансы → Категории**.
2. Нажмите кнопку **Экспорт**.
3. Система автоматически скачает CSV-файл.

[[info type=custom color=#E06823]] В экспорт включаются только категории, которые не скрыты[[/info]]

---

## Состав CSV-файла

| Поле | Описание |
|------|----------|
| **Geo** | Значение, выбранное в поле **Geo** на момент экспорта. |
| **ID** | Уникальный идентификатор категории. |
| **Category** | Название категории. |
| **Type** | Тип категории: `Расход`, `Доход` или `Все`. |
| **Comment** | Содержимое поля **Comment**, если оно заполнено. |

## Создание категории

Чтобы создать новую категорию:

1. Откройте раздел **Финансы → Категории**
2. Нажмите **+Создать**
3. Заполните поля
4. Нажмите **Сохранить**

### Поля категории

| Поле | Описание | Обязательное поле |
|------|----------|:-----------------:|
| **Имя** | Название категории. Должно быть уникальным в рамках системы. Длина — от 3 до 50 символов | ✅ |
| **Родительская категория** | Родительская категория, внутри которой будет создана новая категория | ✅ |
| **Тип транзакций** | Тип транзакций, которые могут относиться к категории | ✅ |
| **Комментарий** | Необязательный комментарий. Максимальная длина — 250 символов | — |

### Выбор типа категории

Доступные типы:

| Тип | Назначение |
|------|------------|
| `Все` | Универсальная категория. Может содержать подкатегории и транзакции любых типов |
| `Доход` | Категория только для доходных транзакций |
| `Расход` | Категория только для расходных транзакций |

### Ограничения при выборе типа

Доступные значения поля **Тип транзакций** зависят от типа родительской категории

> ⚠️ Если родительская категория имеет тип:
>
> - **Все** — доступны типы `Все`, `Доход` и `Расход`
> - **Доход** — доступен только `Доход`
> - **Расход** — доступен только `Расход`

Если у выбранной родительской категории доступен только один тип, он будет выбран автоматически, а поле станет недоступным для изменения.

### Изменение родительской категории

При изменении родительской категории система повторно проверяет совместимость типа категории.

- если выбранный тип совместим с новым родителем — значение сохраняется;
- если несовместим — поле **Тип транзакций** очищается, после чего необходимо выбрать допустимый тип

# Редактирование категории


## Изменение названия

Поле **Имя** доступно для редактирования как у пользовательских, так и у дефолтных категорий. При переименовании дефолтной категории изменяется только её название, а ярлычок остается прежним.


## Изменение родительской категории

Категорию можно перенести в другую родительскую категорию, если их типы совместимы.

| Текущий тип | Куда можно перенести |
|-----------------------------|----------------------|
| **Доходы** | В категорию **Доходы** или **Все** |
| **Расходы** | В категорию **Расходы** или **Все** |
| **Все** | Только в категорию **Все** |

При переносе категории вместе с ней перемещаются все её дочерние категории. При этом типы дочерних категорий не изменяются.


## Изменение типа категории

У дефолтных категорий поле **Тип транзакций** недоступно для редактирования.

У пользовательских категорий поле **Тип транзакций** доступно для редактирования.

**Редактирование типа пользовательской категории**

| Текущий тип | Можно изменить на |
|--------------|-------------------|
| **Доходы** | **Все**, если родительская категория имеет тип **Все** |
| **Расходы** | **Все**, если родительская категория имеет тип **Все** |
| **Все** | Изменение недоступно |

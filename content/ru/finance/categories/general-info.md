## Категории


Это дерево финансовых статей, которое используется для классификации всех транзакций и помогает вести финансовый учет.
Система автоматически создает набор стандартных категорий, а пользователь может дополнять его собственными в зависимости от потребностей бизнеса.

Каждая категория имеет тип (**Доход**, **Расход** или **Все**), может быть **дефолтной** (созданной системой автоматически при создании локации) или **пользовательской** (созданной вручную), и занимает свое место в иерархии категорий.

## Типы категорий

| ENG | RU | Описание |
|-----|----|----------|
| **Income** | Доходы | Тип категории, к которой могут относиться только **доходные (входящие)** транзакции. |
| **Expenses** | Расходы | Тип категории, к которой могут относиться только **расходные (исходящие)** транзакции. |
| **All** | Все | Универсальный тип категории, который может содержать подкатегории и транзакции **любых типов** (**Доходы** или **Расходы**). |

## Дефолтные категории



![Создание категории](/ru/images/categories/categories.png)

 [[delimiter rows=1]]

Это 8 категорий, которые система автоматически создаёт **при создании новой локации**. Они покрывают основные ежедневные финансовые потоки заведения и отмечаются ярлычком с замком. Название ярлычка изменить нельзя.

 - **Общая/General** (All)
   - Эквайринг/Acquiring (Expenses)
   - Чаевые/Tips (Income)
   - Выручка смены/Cash Shifts (All)
   - Прибыль/Profit (Expenses)
 - **Зарплата/Salary** (Expenses)
 - **Actualization** (All)
 - **Трансфер/Transfer** (All)

 После создания локации пользователь может расширять это дерево собственными категориями в зависимости от структуры бизнеса.

 Все дефолтные категории создаются внутри **Main Category** - это родительская корневая категория. Она не используется в транзакциях, служит только контейнером для остальных категорий


 ## Описание категорий

 | Название категории  | Тип категории | Описание |
|--------------------------------------------|---------------|----------|
| **General / Общая** | **Все** | Базовая универсальная категория. Используется как категория по умолчанию, если транзакция ещё не распределена по конкретной категории |
| **Acquiring / Эквайринг** | **Расходы** | Комиссии банка за эквайринг.<br><br>При поступлении платежей на банковский аккаунт по категориям **Выручка смены** и **Чаевые** система автоматически создаёт **расходные транзакции** по категории **Эквайринг** в соответствии с заданным в аккаунте (на который пришёл входящий платёж) процентом эквайринга |
| **Tips / Чаевые** | **Доход** | Безналичные чаевые |
| **Cash Shifts / Выручка смены** | **Все** | Выручка заведений |
| **Profit / Прибыль** | **Расход** | Вывод средств собственником: дивиденды, вывод прибыли и аналогичные операции |
| **Salary / Зарплата** | **Расход** | Фонд оплаты труда: зарплаты, выплаты, бонусы |
| **Actualization / Актуализация** | **Все** | Корректирующие операции, которые используются для уточнения финансовых данных и приведения сумм к фактическим значениям |
| **Transfer / Трансфер** | **Все** | Категория для транзакций, связанных с перемещением денежных средств между аккаунтами одной локации  |


## Поиск категорий

Поиск позволяет быстро найти нужную категорию.

Поиск:
- ищет совпадения в названии категории;
- ищет совпадения в комментарии;
- выполняется моментально по мере ввода текста;
- не учитывает регистр символов;
- отображает только категории, соответствующие поисковому запросу.

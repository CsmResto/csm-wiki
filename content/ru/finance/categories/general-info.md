## Категории


Это дерево финансовых статей, которое используется для классификации всех транзакций и помогает вести финансовый учет.
Система автоматически создает набор стандартных категорий, а пользователь может дополнять его собственными в зависимости от потребностей бизнеса.

Каждая категория имеет тип (**Income**, **Expenses** или **All**), может быть **дефолтной** (созданной системой автоматически при создании локации) или **пользовательской** (созданной вручную), и занимает свое место в иерархии категорий.

## Типы категорий

| ENG | RU | Описание |
|-----|----|----------|
| **Income** | Доходы | Тип категории, к которой могут относиться только **доходные (входящие)** транзакции. |
| **Expenses** | Расходы | Тип категории, к которой могут относиться только **расходные (исходящие)** транзакции. |
| **All** | Все | Универсальный тип категории, который может содержать подкатегории и транзакции **любых типов** (**Income** или **Expenses**). |

## Дефолтные категории

ℹ️ **Дефолтные категории**

![Создание категории](/ru/images/categories/categories.png)

Это 8 категорий, которые система автоматически создаёт **при создании новой локации**. Они покрывают основные ежедневные финансовые потоки заведения.

 - **Общая/General** (All)
   - Эквайринг/Acquiring (Expenses)
   - Чаевые/Tips (Income)
   - Выручка смены/Cash Shifts (All)
   - Прибыль/Profit (Expenses)
 - **Зарплата/Salary** (Expenses)
 - **Actualization** (All)
 - **Трансфер/Transfer** (All)

 После создания локации пользователь может расширять это дерево собственными категориями в зависимости от структуры бизнеса.


 [[info type=custom color=#E06823]]
⚠️   **Дефолтные категории помечаются лейблом**

   - дефолтные категории помечаются лейблом — это их исходное системное название
   - лейбл **не меняется**, даже если пользователь изменяет поле **Name** у дефолтной категории
   - лейблы отображаются на языке интерфейса
   - названия (**Name**) всех существующих категорий при релизе сохраняются без изменений

 Все дефолтные категории создаются внутри **Main Category** - это родительская корневая категория. Она не используется в транзакциях, служит только контейнером для остальных категорий
 [[/info]]

 ## Описание категорий

 | Название категории  | Тип категории | Описание |
|--------------------------------------------|---------------|----------|
| **General / Общая** | **All** | Базовая универсальная категория. Используется как категория по умолчанию, если транзакция ещё не распределена по конкретной категории |
| **Acquiring / Эквайринг** | **Expenses** | Комиссии банка за эквайринг.<br><br>При поступлении платежей на банковский аккаунт по категориям **Cash Shifts** и **Tips** система автоматически создаёт **расходные транзакции** по категории **Acquiring** в соответствии с заданным в аккаунте (на который пришёл входящий платёж) процентом эквайринга |
| **Tips / Чаевые** | **Income** | Безналичные чаевые |
| **Cash Shifts / Выручка смены** | **All** | Выручка заведений |
| **Profit / Прибыль** | **Expenses** | Вывод средств собственником: дивиденды, вывод прибыли и аналогичные операции |
| **Salary / Зарплата** | **Expenses** | Фонд оплаты труда: зарплаты, выплаты, бонусы |
| **Actualization / Актуализация** | **All** | Корректирующие операции, которые используются для уточнения финансовых данных и приведения сумм к фактическим значениям |
| **Transfer / Трансфер** | **All** | Категория для транзакций, связанных с перемещением денежных средств между аккаунтами одной локации  |

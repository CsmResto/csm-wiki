**Cosmos Team** - мобильное приложения для входа на смены, просмотра зарплат, квестов и модификаторов.

Ссылка на iOS: [App Store](https://apps.apple.com/uz/app/cosmos-team/id6780405989)

Ссылка на Android: [Google Play](https://play.google.com/store/apps/details?id=ru.cosmosresto.team)

### Инструкция для входа:

1. Открыть приложение

2. В поле **"Connection"** ввести значение, обозначающее принадлежность к вашему заведению

    **Как узнать:** Возьмите часть ссылки, по которой открываете Cosmos в браузере. Нужная часть ссылки указана до csmresto.ru. Например, для https://demo.csmresto.ru/ значение — **demo**. Если сомневаетесь, значение можно уточнить у техподдержки

3. Кликнуть **"Подключиться"**

4. Ввести данные сотрудника для входа

5. Кликнуть **"Войти"**

[[info type=custom color=#E06823]]
Если при попытке войти возникает проблема `"Сервер временно недоступен"`, то скорее всего значение на втором шаге было введено неверно. Для этого нужно:

1. Кликнуть на текст **"Вернуться к выбору приложения"**
2. В поле **"Подключиться к"** ввести значение, обозначающее принадлежность к вашему заведению
3. Кликнуть **"Подключиться"**
4. Ввести данные сотрудника для входа
5. Кликнуть **"Войти"**

Если проблема повторяется, напишите в техническую поддержку, мы поможем разобраться
[[/info]]

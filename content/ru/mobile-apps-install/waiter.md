**Cosmos Waiter** - мобильное приложение для официанта для регистрации заказов и просмотра информации о госте.

Ссылка на iOS: [App Store](https://apps.apple.com/sg/app/cosmos-waiter/id6779239041)

Ссылка на Android: [Google Play](https://play.google.com/store/apps/details?id=ru.cosmosresto.waiter)

Для входа в приложение необходимо отсканировать QR-код с кассы.

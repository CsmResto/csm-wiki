Импорт расписания позволяет быстро загрузить смены для нескольких сотрудников на выбранной локации.

**Шаблоны импорта:**

[[document src="/ru/documents/team/импорт смен с зонами формат xlsx.xlsx" title="импорт смен с зонами формат xlsx" meta="Документ · XLSX"]]

[[document src="/ru/documents/team/импорт смен с зонами формат csv.csv" title="импорт смен с зонами формат csv" meta="Документ · CSV"]]

## Как загрузить смены

**1.** Нажмите `Импорт расписания` в разделе Смены.

![shifts-import-button](/ru/images/team/shifts-import-button.jpg)

[[delimiter]]

**2.** В открывшемся модальном окне укажите:
1. Локацию.
2. Месяц, для которого загружается график (*по умолчанию подставляются значения, выбранные в разделе Смены*).
3. Загрузите файл с графиком. Поддерживаются форматы **CSV** или **Excel(XLSX)**.

![shifts-import-button](/ru/images/team/shifts-import-modal.jpg)

[[delimiter]]

[[info type=custom color=#E06823]]
Если в файле обнаружатся ошибки, импорт будет остановлен, а система покажет, какие строки нужно исправить.
[[/info]]

## Формирование файла

<!-- Вы можете подготовить расписание в удобном инструменте, например на сайте https://planimum.ru/, и затем выгрузить его по шаблону для импорта. -->
**Описание полей:** 
- **start_year** — год начала смены
- **start_month** — месяц начала смены
- **start_day** — день начала смены
- **start_hour** — час начала смены (в 24-часовом формате)
- **start_minute** — минуты начала смены
- **end_year** — год окончания смены
- **end_month** — месяц окончания смены
- **end_day** — день окончания смены
- **end_hour** — час окончания смены (в 24-часовом формате)
- **end_minute** — минуты окончания смены
- **employeeId** — уникальный идентификатор пользователя в системе
- **roleId** — уникальный идентификатор роли в системе
- **zone** — название зоны (*необязательное поле*)

Узнать roleId можно в карточке роли в URL

## Возможные ошибки и их причины

| Ошибка                                                         | Когда возникает                                                                                  |
| -------------------------------------------------------------- | ------------------------------------------------------------------------------------------------ |
| **Недостаточно прав для управления выбранной ролью**           | В файле указаны роли, которыми у вас нет доступа управлять.                                      |
| **Сотруднику нельзя назначить смену в выбранной локации**      | В файле указаны сотрудники, которые не привязаны к выбранной локации.                            |
| **Дата или время смены выходят за пределы выбранного периода** | В файле указаны некорректные дата или время начала/окончания смены.                              |
| **Время начала смены позже времени окончания**                 | В одной или нескольких строках файла время начала смены указано позже времени окончания.         |
| **Обнаружены пересекающиеся смены**                            | В файле есть смены с пересекающимся временем.                                                    |
| **У сотрудника уже есть смена на это время**                   | Для сотрудника уже существует смена в другой локации на тот же период времени.                   |
| **У сотрудника отсутствует указанная роль**                    | В файле указана роль, которая не назначена сотруднику.                                           |
| **Сотрудник не найден или у вас нет доступа к нему**           | В файле указан несуществующий сотрудник либо у вас недостаточно прав для управления его сменами. |
| **Длительность смены превышает допустимый лимит**              | В файле есть смены длительностью более 48 часов.                                                 |
| **Не удалось обработать файл**                                 | Произошла ошибка при чтении данных из загруженного файла.                                        |
| **Указанная зона не найдена в выбранной локации**              | В колонке `Zone` указано название зоны, которого нет среди настроенных зон выбранной локации.    |

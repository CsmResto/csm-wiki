После настройки ролей необходимо создать пользователей, которые будут работать в системе Cosmos.

**Для создания пользователя потребуются следующие обязательные данные:**
- Имя
- Фамилия
- Пол
- Адрес электронной почты
- Локация
- Роль

Остальные поля можно заполнить позднее при необходимости.


### Создание нового пользователя

**1.** Перейдите в раздел **Команда -> Пользователи**.

**2.** Нажмите кнопку **Создать**.

**3.** Заполните изформацию о пользователе:

- **Имя**

- **Фамилия**

- **Электронная почта** - на неё придет письмо с доступом в Cosmos

- **Пол**

- **Номер телефона** - можно заполнить рандомно

- **Номер паспорта** - можно заполнить рандомно

- **Гео** - локация, в которой работает сотрудник
    - `Локация` — если сотрудник работает в конкретном заведении.
    - `Регион` — если сотрудник работает с несколькими заведениями внутри одного региона.
    - `World` — если сотруднику требуется доступ ко всем заведениям во всех регионах.

[[info type=custom color=#E06823]]
Выбранное значение влияет на перечень объектов, которые сотрудник сможет видеть и редактировать в системе.
[[/info]]

- **Роль**

[[info type=custom color=#E06823]]
Если у сотрудника **несколько ролей**, появится поле `Основная роль`, в ней нужно будет выбрать **одну**, по которой будут определяться доступы и зарплата (если подключена).
[[/info]]

- **Дата найма** - можно заполнить сегодняшним днем

- **Результат экзамена** - можно заполнить рандомно


**4.** Проставьте автоматическую генерацию пароля **или** введите придуманный пароль.

**5.** Нажмите кнопку **Создать**.

**Cloud API** — сервис для обмена данными между IIKO и внешними системами. Интеграция используется для подключения COSMOS к IIKO через API-ключ.

## Интеграция IIKO Cloud API и COSMOS:

**1.** Выполните вход в IIKO Web.

**2.** Перейдите в раздел `Внешние заказы -> Настройка iikoCloud API`.

**3.** Во вкладке `Интеграции` и нажмите `+ Добавить интеграцию`.

![iiko-cloud](/ru/images/connection/iikocloud-connect/iikocloud-connect-1.png)

[[delimiter rows=1]]

**4.** На вкладке `Основное` заполните следующие поля:

- **Имя API-логина** — укажите удобное название интеграции
- **Шаблон прав** — выберите значение `Все права`
- **Email** — укажите адрес электронной почты `cosmos@darwinsoft.ru`
- **Отключите настройку** `Проставить срок действия API ключа`

[[info type=custom hasIcon icon=warning color=#E06823]]
Сразу скопируйте и сохраните API-ключ. Для ключей без даты окончания ключ показывается только один раз в момент создания.
[[/info]]

![iiko-cloud](/ru/images/connection/iikocloud-connect/iikocloud-connect-2.png)

[[delimiter rows=1]]

**5.** Перейдите на вкладку `Подключенные точки` и нажмите `+ Добавить точку`.

![iiko-cloud](/ru/images/connection/iikocloud-connect/iikocloud-connect-3.png)

[[delimiter rows=1]]

**6.** Выберите **все точки** нажмите `Добавить`.

![iiko-cloud](/ru/images/connection/iikocloud-connect/iikocloud-connect-4.png)

[[delimiter rows=1]]

**7.** Сохраните созданную интеграцию.

**8.** Передайте `API-ключ` в службу поддержки COSMOS.

**9.** После получения ключа специалисты COSMOS завершат настройку интеграции и сообщат дальнейшие шаги.

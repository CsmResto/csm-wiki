### Поздравляем, теперь вы - часть космоса :)

Эта статья поможет понять, какие этапы необходимо пройти для подключения к системе. Здесь вы узнаеме, какую информацию мы будем запрашивать от вас, инструкции и ссылки на них.

[[info type=custom color=#E06823]]
Все вопросы по подключению и дальнейшей работе с системой будут решаться через чат с командой поддержки Cosmos.
[[/info]]

## Этап 1. Подписание договора

На этапе согласования и подписания договора мы уточняем базовую информацию о вашем проекте:

- количество локаций;
- перечень модулей Cosmos, которые планируется использовать.

После подписания договора мы создадим общий чат **«Вы & Cosmos Support»**, который будет использоваться:

- для коммуникации во время подключения;
- для передачи необходимых данных и материалов;
- для дальнейшей технической поддержки.

## Этап 2. Создание локаций

Для настройки локаций потребуется следующая информация.

**Обязательные данные:**

- название локации;
- часы работы;
- часовой пояс (Time Zone);
- валюта;
- время закрытия операционного дня (Checkout Time).

**Дополнительные данные:**

- площадь заведения;
- контактный номер телефона.

После получения информации мы создадим ваши локации в системе Cosmos.

## Этап 3. Создание директора и первичного доступа

Для предоставления первого доступа в систему необходимо предоставить данные пользователя с ролью директора.

**Обязательные данные:**

- имя;
- фамилия;
- пол;
- адрес электронной почты.

На указанный email будет отправлено приглашение для входа в систему.

**Дополнительные данные:**

- дата рождения;
- номер телефона.

После получения информации мы создадим пользователя и назначим ему роль директора.

## Этап 4. Настройка ролей сотрудников

На этом этапе необходимо предоставить список ролей, которые будут использоваться в вашей компании.

По умолчанию сотрудники получают доступ только к тем разделам системы, которые необходимы для выполнения их обязанностей.

### Сотрудники зала

Официанты, бармены и другие сотрудники зала имеют доступ к личному кабинету, где могут:

- просматривать свои данные;
- видеть назначенную роль;
- просматривать информацию по сменам;
- работать с доступными им модулями.

### Маркетологи

Сотрудники отдела маркетинга обычно получают доступ к следующим модулям:

- Гости;
- Сегменты;
- Автотеги;
- Кампании;
- другие маркетинговые инструменты.

### Управляющие и руководители

В зависимости от задач могут получать доступ к:

- аналитике;
- отчетам;
- бронированиям;
- управлению персоналом;
- настройкам системы.

После согласования структуры доступа мы создадим необходимые роли в системе.


## Этап 5. Создание остальных пользователей

Вам на почту придет доступ для входа в Cosmos - вы сможете попасть в систему и уже начать ее изучать. 

Первой задачей будет создать остальных пользователей системы. 

**[Инструкция по созданию пользователей](https://wiki.cosmosresto.ru/ru/team/users/user-creation)**

**Необходимые данные для создания пользователя:**

- имя;
- фамилия;
- пол;
- адрес электронной почты;
- локация;
- роль.

**Дополнительные данные:**

- номер телефона;
- дата рождения;
- другие пользовательские поля.

[[info type=custom color=#E06823]]
Дополнительные данные можно заполнить позже при необходимости.
[[/info]]

## Этап 6. Создание плана этажа

Для настройки схемы размещения столов потребуется план вашего заведения.

**Необходимо предоставить:**

- схему расположения столов;
- вместимость каждого стола.

**После настройки столы будут доступны:**

- в разделе `Бронирования -> План этажа`;
- в модуле бронирования в режиме `Floor Plan View`.

## Этап 7. Настройка интеграции с IIKO

**Для подключения интеграции потребуется выполнить несколько шагов:**

**1.** Предоставить удалённый доступ к вашему компьютеру для установки плагина.

**2.** Предоставить поддержке Cosmos API-ключ подключенного соединения. Для этого нужно выполнить настройку интеграции IIKO Cloud Api и Cosmos. 

**[Инструкция: Настройка интеграции IIKO Cloud API и Cosmos](https://wiki.cosmosresto.ru/ru/connection/iikocloud-connect)**

**3.** Создать технического пользователя Cosmos в IIKO. Для этого нужно создать должность, пользователя и выдать необходимые права доступа.

**[Инструкция: Создание пользователя Cosmos в IIKO](https://wiki.cosmosresto.ru/ru/connection/iikouser-create)**

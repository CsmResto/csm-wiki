### Поздравляем, теперь вы - часть космоса :)

Эта страница создана для того, чтобы вы знали, какие этапы вас ждут в процессе подключения к нашему продукту. Здесь можно будет узнать, какую информацию мы будем запрашивать от вас, инструкции и ссылки на них.

Начнем.

## Этап 1. Подписание договора

На этом этапе мы выясняем информацию, которая потребуется для подключения:

- Количество локаций
- Какие модули COSMOS будут подключаться

После подписания мы создаем чат **Вы & Cosmos Support**, добавляем туда нас и вас. Этот чат будет использоваться:

- Для коммуникаций во время подключения
- Для запросов и передачи необходимой информации
- Для дальнейшей технической поддержки

## Этап 2. Создание локаций

Для настройки локаций потребуется следующая информация:

- Название локации
- Часы работы
- Таймзона
- Валюта
- Время закрытия операционного дня - Checkout time

Дополнительная информация (можно предоставить по желанию):

- Площадь
- Номер телефона

После получения информации мы создаем локацию в Cosmos.

## Этап 3. Создание пользователя и роли директора

Чтобы предоставить вам доступ в систему, нам потребуется следующая информация:

- Имя
- Фамилия
- Пол
- Адрес электронной почты

Дополнительная информация (можно предоставить по желанию):

- Дата рождения
- Номер телефона

После получения информации мы создаем роль директора и пользователя в Cosmos.

[[info type=custom color=#E06823]]
Вам на почту придет доступ для входа в Cosmos - вы сможете попасть в систему и уже начать ее изучать, но для первой задачи - создание пользователей - сначала мы создадим для вас роли.
[[/info]]

## Этап 4. Создание ролей сотрудников

Для этого нам потребуется **список ролей, которыми вы будете пользоваться.**

После получения информации мы создаем роли для ваших будущих сотрудников в Cosmos.

По умолчанию сотрудникам зала - официантам, барменам - мы будем выдавать доступ только к перечисленным модулям:

- Дашборд (просмотр ФИО, роли, локации)
- Смены

Сотрудникам маркетинга выдадим доступ до гостевых модулей:

- Гости
- Сегменты
- Ручные теги
- Автотеги
- Рассылки
- Мониторинг рассылок
- Группы рассылок
- RFM


## Этап 5. Создание пользователей

Теперь, когда у вас есть доступ в Cosmos, настроены локации и роли, вы можете создать остальных пользователей системы.

**[Инструкция по созданию пользователей](https://wiki.cosmosresto.ru/ru/team/users/user-creation)**

**Заранее сообщим, какие данные вам потребуются обязательно::**

- Имя
- Фамилия
- Пол
- Адрес электронной почты
- Локация
- Роль

[[info type=custom color=#E06823]]
Остальные поля (номер телефона, дата рождения и другие) можно будет заполнить рандомно и актуализировать позже при необходимости.
[[/info]]

## Этап 6. Создание плана этажа

Для этого нам потребуется план этажа вашего заведения - **расположение столов, количество гостей на каждый стол.**

После получения информации мы создадим столы в Cosmos.

**После настройки столы будут доступны:**

- в разделе `Бронирования -> План этажа`;
- в модуле бронирования в режиме `Floor Plan View`.

## Этап 7. Настройка интеграции с IIKO

**Для этого нам потребуется:**

**1.** Удаленный доступ к вашему компьютеру для установки плагина.

**2.** API-ключ подключенного соединения. Для этого нужно выполнить настройку интеграции IIKO Cloud Api и Cosmos.

**[Инструкция: Настройка интеграции IIKO Cloud API и Cosmos](https://wiki.cosmosresto.ru/ru/connection/iikocloud-connect)**

**3.** Сотрудник COSMOS в вашей IIKO. Для этого нужно создать должность и пользователя и выдать необходимые права. 

**[Инструкция: Создание пользователя Cosmos в IIKO](https://wiki.cosmosresto.ru/ru/connection/iikouser-create)**


**Также для настройки некоторых других интеграций у нас есть отдельные инструкции:**

- **[Интеграция IIKO Card и Cosmos](https://wiki.cosmosresto.ru/ru/connection/iikocard-webhook)**
- **[Подключение CardPR & Passquare](https://wiki.cosmosresto.ru/ru/connection/cardpr-connect)**
- **[Подключение RedSMS & Twilio](https://wiki.cosmosresto.ru/ru/connection/redsms-twilio-connect)**

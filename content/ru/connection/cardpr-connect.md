**CARDPR и Passquare** — сервисы для управления электронными картами лояльности. Они позволяют настроить форму регистрации в программе лояльности и оформить внешний вид электронной карты для гостей.

- **[CARDPR](https://ru.cardpr.com/)** - интеграция с IIKO (Россия).
- **[Passquare](https://passquare.com/)** - интеграция c Syrve (Все страны, кроме России).

### Этапы настройки интеграции

[[info type=custom color=#E06823]]
Процесс настройки **одинаков** для CARDPR и Passquare. **Выбор сервиса зависит от региона использования.**
[[/info]]

1. Создайте личный кабинет в CARDPR(для РФ) или Passquare(для остальных стран).
2. Выберите и оплатите подходящий тарифный план.
3. Создайте и настройте внешний вид электронной карты.
4. Создайте форму выдачи карт для программы лояльности.
5. Настройте SMS-верификацию для проверки уникальности данных гостей.
6. Добавьте Webhook для интеграции с Cosmos.

## Создание и настройка карты

1. Перейдите в раздел `Шаблоны карт/Card templates`.

2. Создайте новый шаблон карты.

3. Укажите название карты и настройте интересующие поля:
    - Логотип
    - Заголовок и иконка push-сообщения
    - Визуальное оформление
    - Дополнительные поля

4. Сохраните шаблон карты.

[[info type=custom color=#E06823]]
В текстовых полях можно использовать **переменные**, например имя гостя или размер скидки. Полный список доступных переменных находится в разделе `Настройки/Settings -> Переменные/Variables`
[[/info]]

## Создание формы выдачи карт

1. Перейдите в раздел `Выдача карт/Card issuance`.

2. Создайте новую форму выдачи карт.

3. В разделе `Параметры/Parameters` заполните следующие поля:
    - Название
    - Заголовок
    - Описание (необязательно)
    - Шаблон карты
    - Цветовая схема
    - Язык
    - В блоке **Верификация** укажите SMS
    - Формат номера телефона
    - Обязательно поставить галочку на пункте **Сохранять полный номер с кодом страны**

![card1](/ru/images/connection/cardpr-connect/cardpr-connect-4.png)

4. В разделе `Поля/Fields` укажите минимально необходимые поля:
    - Имя
    - Номер телефона
    - Пол
    - Согласие на обработку персональных данных
    - Согласие на получение маркетинговых рассылок

![card1](/ru/images/connection/cardpr-connect/cardpr-connect-5.png)

*Пример заполнения формы*

[[info type=custom color=#E06823]]
Чтобы добавить **поле согласия на маркетинговые рассылки**, создайте переменную `marketing_consent` в разделе `Настройки/Settings -> Переменные/Variables` и укажите её в переменных поля.

![card1](/ru/images/connection/cardpr-connect/cardpr-connect-6.png)
[[/info]]

5. В разделе `Соглашение/Agreement` добавьте текст условий, с которыми должен согласиться гость.

6. Сохраните форму выдачи карт.

[[info type=custom color=#E06823]]
После сохранения формы вы сможете скопировать ссылку на неё или скачать QR-код для быстрого доступа гостей.
[[/info]]

## Настройка SMS-верификации

Для настройки SMS-верификации можно использовать любой сервис рассылок, поддерживаемый CARDPR или Passquare.

**[Инструкция настройки верификации от CARDPR.](https://ru.cardpr.com/help/forms/phone-verification-more)**

Использование **REDSMS или Twilio** позволит применять один сервис как для SMS-верификации, так и для маркетинговых рассылок через **Cosmos**.

- **[REDSMS](https://redsms.ru/)** - для России.
- **[Twilio](https://www.twilio.com/)** - для всех остальных стран.


## Добавление Webhook для интеграции с Cosmos

1. Перейдите в раздел `Настройки/Settings -> API`

2. Найдите параметр `Приватный ключ/Private Key`. Передайте значение приватного ключа в службу поддержки Cosmos.

3. Запросите у поддержки Cosmos данные для настройки Webhook:
    - URL
    - Пароль 

4. Перейдите в раздел `Интеграция/Integration`

5. Выберите тип интеграции:
    - `URL / 1c` для **CARDPR**
    - `URL` для **Passquare**

5. Укажите `Сервер/Server` и `Пароль/Password`, предоставленные поддержкой Cosmos.


[[info type=custom color=#E06823]]
Если необходимо отображать количество бонусов на электронной карте гостя, сообщите в поддержку Cosmos **название основной бонусной программы из IIKO Card**. В IIKO Card **тип программы** должен быть `Бонусная программа`.
[[/info]]

**Теги бронирований** помогают вручную отмечать бронирования внутри CRM. С их помощью можно визуально выделять важные записи, быстро понимать контекст бронирования, группировать бронирования и находить их с помощью фильтров.

Например, можно создать теги `Нужна парковка`, `Позднее прибытие`, `Высокий приоритет` или `Требует внимания менеджера`.

[[info type=custom color=#E06823]]
Теги бронирований **не связаны с тегами гостей**. Это отдельные типы тегов, которые настраиваются и используются независимо друг от друга.
[[/info]]


## Список тегов

В разделе **Бронирования -> Теги бронирований** отображается список созданных тегов и основная информация о них. В данном разделе можно просматривать, создавать и редактировать теги.

![Теги](/ru/images/reserve/reservations-tags/reservations-tags1.jpg)

### Поиск, фильтрация и сортировка

- **Поиск:** по полю Название — поиск начинается после ввода не менее трёх символов.

- **Фильтрация:** по Локациям, Дате создания/обновления, Автору.

- **Сортировка:** по названию, короткому имени, дате создания или дате последнего обновления.

## Создание тега

**1.** Откройте раздел **Бронирования -> Теги бронирований**.

**2.** Нажмите **Создать**.

**3.** Заполните поля:

[[gallery gap=12 layout=carousel]]
![Теги](/ru/images/reserve/reservations-tags/reservations-tags2.jpg)
![Теги](/ru/images/reserve/reservations-tags/reservations-tags3.jpg)
[[/gallery]]

1. **Локации** — заведения, в которых доступен тег. При добавлении тега в бронирование система показывает только теги, доступные для выбранной локации;
2. **Название** — полное название тега. Должно быть уникальным от 3 до 25 символов;
3. **Короткое имя** — сокращение, которое отображается на бронировании. Должно быть уникальным от 1 до 3 символов;
4. **Текст подсказки** — пояснение, которое отображается при наведении на тег;
5. **Описание** — дополнительная информация о назначении тега;
6. **Цвет** - цветовое оформление тега;
7. **Иконка** — визуальное обозначение тега;

**4.** При необходимости добавьте описание, иконку и текст подсказки.

**5.** Нажмите **Сохранить**.

[[info type=custom color=#E06823]]
После сохранения тег появится в общем списке тегов и станет доступен в списке тегов при редактировании бронирования.
[[/info]]

[[delimiter rows=1]]

### Редактирование тега

В существующем теге **можно редактировать все поля**. 

После сохранения **изменения применяются ко всем бронированиям, в которых используется тег**. Перед сохранением система предупреждает, что изменение может повлиять на связанные бронирования.

Подробности изменения и создания тега можно увидеть внутри карточки тега.

![Теги](/ru/images/reserve/reservations-tags/reservations-tags4.jpg)

[[delimiter rows=1]]

### Удаление тега

1. Откройте раздел **Бронирования -> Теги бронирований**.
2. Найдите нужный тег.
3. Кликните на тег, открыв редактирование. 
4. Нажмите **Удалить**.

![Теги](/ru/images/reserve/reservations-tags/reservations-tags5.jpg)

[[delimiter rows=1]]

5. Подтвердите удаление.

![Теги](/ru/images/reserve/reservations-tags/reservations-tags6.jpg)

[[delimiter rows=1]]

**После удаления:**

- Тег полностью исчезнет из системы;
- Тег будет удалён из всех связанных бронирований;
- Тег станет недоступен для назначения и фильтрации;
- Журнал изменений бронирований, где ранее был указан этот тег, не изменится.

## Использование тегов в бронированиях

### Добавление тега

Одному бронированию можно назначить несколько тегов. В списке отображаются только теги, доступные для локации этого бронирования.

![Теги](/ru/images/reserve/reservations-tags/reservations-tags7.jpg)

[[delimiter rows=1]]

1. Откройте нужное бронирование.
2. Нажмите **Добавить тег**.
3. Найдите тег по названию или выберите его из списка.
4. При необходимости выберите другие теги.
5. Нажмите **Сохранить**.

[[info type=custom color=#E06823]]
После сохранения выбранные теги будут связаны с бронированием и появятся в его боковой панели.
[[/info]]

### Удаление тега из бронирования

1. Откройте бронирование.
2. Нажмите значок удаления рядом с тегом.
3. Нажмите **Сохранить**.

[[info type=custom color=#E06823]]
Тег будет удалён только из выбранного бронирования. Сам тег останется доступен в системе и продолжит использоваться в других бронированиях.
[[/info]]

### История изменений

Система сохраняет действия с тегами в истории бронирования. Время и автора добавления или удаления тега можно увитеть в Журнале изменений.

![Теги](/ru/images/reserve/reservations-tags/reservations-tags8.jpg)

[[delimiter rows=1]]

### Фильтрация бронирований по тегам

1. Откройте раздел `Бронирования`.
2. Перейдите в табличный режим отображения.
3. Откройте фильтр по тегам.
4. Выберите один или несколько тегов.

В таблице останутся бронирования, соответствующие выбранным условиям. Для фильтра доступны теги выбранной локации.

![Теги](/ru/images/reserve/reservations-tags/reservations-tags9.jpg)

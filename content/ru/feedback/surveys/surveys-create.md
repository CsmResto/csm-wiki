Конструктор позволяет собрать опрос из страниц и вопросов, настроить сценарий прохождения и оформить форму для респондента.

Чтобы создать черновик, необходимо заполнить обязательные поля основной информации и добавить **как минимум один вопрос**.

## Создание опроса

1. Откройте раздел **Опросы**.
2. Нажмите `Создать`.
3. На шаге **Детали** укажите название и локацию.
4. На шаге **Вопросы** настройте структуру опроса.
5. При необходимости настройте переходы между этапами опроса на шаге **Условия**.
6. При необходимости измените внешний вид на шаге **Дизайн**.
7. Нажмите `Создать` на последнем шаге.

После успешного сохранения система создаст опрос со статусом `Черновик`. На странице опроса станет доступен раздел **Распространение**, а кнопку `Создать` заменит кнопка `Сохранить`.

### Типы страниц

- **Страница с вопросами**

Используйте страницу с вопросами для сбора ответов. На одной странице может находиться один или несколько вопросов, и весь ее контент отображается респонденту одновременно.

- **Стартовый экран**

Стартовый экран отображается перед вопросами и может быть только один. Его можно использовать для приветствия, пояснения цели опроса или получения согласия на обработку персональных данных.

На стартовом экране можно добавить текст и переменные, добавить изображение, включить согласие на обработку персональных данных и добавить возможность отписаться от рассылок опросов.

- **Информационный экран**

Информационный экран можно размещать между страницами с вопросами. Он не требует ответа и подходит для инструкций, пояснений или визуальных вставок.

На экране можно добавить текст, переменные и изображение.

- **Финальный экран**

Финальный экран завершает сценарий прохождения. В опросе может быть несколько финальных экранов, например для разных веток сценария.

На финальном экране можно добавить текст, переменные, изображение и возможность отписаться от рассылок опросов.

[[info type=custom color=#E06823]]
Если в опросе несколько финальных экранов и условия переходов не настроены, респонденту показывается первый финальный экран по порядку.
[[/info]]

#### Согласие на обработку персональных данных

Настройка доступна только на стартовом экране.

1. Включите `Согласие на продолжение`.
2. Укажите ссылку на политику конфиденциальности.
3. Сохраните изменения.

Респондент увидит обязательный чекбокс согласия. Пока чекбокс не установлен, кнопка `Начать` будет недоступна.

#### Отписка от рассылок опросов

Настройку можно добавить на стартовый или финальный экран.

После подтверждения отписки гость исключается из дальнейших рассылок опросов. Для респондентов, открывших опрос по анонимной ссылке, этот блок не отображается.

[[info type=custom color=#E06823]]
Если опрос открыт по публичной анонимной ссылке, персональные переменные не отображаются.
[[/info]]

Управлять порядком страниц опроса можно, нажав на 2 точки на типе страницы или перетягивать вручную, зажав 6 точек на типе страницы.

### Общие настройки вопроса

<!-- скриншот: типы страниц в конструкторе опроса -->

[[delimiter rows=1]]

Для вопросов доступны следующие базовые параметры:

- **Тип вопроса** — определяет формат ответа: `Оценка`, `NPS`, `Выбор` или `Ввод`.
- **Обязательный** — если включено, респондент не сможет продолжить или отправить опрос без ответа. По умолчанию настройка включена.
- **Текст вопроса** — обязательное поле до 250 символов.
- **Пояснение** — дополнительный текст под вопросом до 250 символов.

#### Оценка

Тип **Оценка** используется для количественной оценки визита, сервиса или другого показателя.

<!-- скриншот: типы страниц в конструкторе опроса -->

[[delimiter rows=1]]

**Доступные настройки:**

- **Тип отображения** — `Звезды` или `Числа`.
- **Учитывать в статистике гостя** — позволяет использовать оценку в условиях автотегов и включаются в статистику гостей.

[[info type=custom color=#E06823]]
Если в одном ответе несколько вопросов типа **Оценка** с включенной настройкой статистики гостя, система использует среднее значение этих оценок для данного ответа.
[[/info]]

#### NPS

Тип **NPS** используется для оценки готовности гостя рекомендовать заведение. Оценивается по шкале от 1 до 10.

<!-- скриншот: типы страниц в конструкторе опроса -->

[[delimiter rows=1]]

#### Выбор

Тип **Выбор** позволяет предложить респонденту готовые варианты ответа.

<!-- скриншот: типы страниц в конструкторе опроса -->

[[delimiter rows=1]]

**Доступные настройки:**

- **Тип выбора** — Одиночный или множественный выбор.
- **Варианты ответа**
- **Другой ответ** — добавляет вариант, при выборе которого респондент вводит собственный текст. Для своего варианта можно изменить название и настроить обязательность и длину вводимого текста.

### Ввод

Тип **Ввод** используется для текстовых ответов и контактных данных. В рамках одного вопроса **можно добавить несколько полей**, например имя, телефон и комментарий. Все заполненные поля сохраняются как один ответ на вопрос.

<!-- скриншот: типы страниц в конструкторе опроса -->

[[delimiter rows=1]]

**Для каждого поля доступны:**

- **Заголовок**
- **Обязательность**
- **Маска** — определяет формат и правила проверки введенного значения. Доступные маски: `Текст`, `Имя`, `Фамилия`, `Телефон`,`Email`.

## Шаг 3. Условия

**Условия** позволяют изменить последовательное прохождение опроса и направлять респондента на разные страницы в зависимости от ответа.

<!-- скриншот: настройка условия При выборе ответа и поля Переход -->

[[delimiter rows=1]]

Если условия не настроены, страницы показываются последовательно.

### Как настроить переход

1. Откройте шаг **Условия**.
2. Найдите нужный вопрос.
3. Нажмите `Добавить условие`.
4. Выберите поведение респондента.
5. Выберите целевую страницу в поле `Переход`.
6. При необходимости добавьте другие условия.

**Доступные условия:**

- **При выборе ответа** — работает для вопросов `Оценка`, `NPS` и `Выбор`. Укажите одно или несколько значений, при которых должен выполняться переход.
- **Всегда** — переход выполняется независимо от ответа.
- **При пропуске** — срабатывает, если респондент не ответил. Доступно только для необязательного вопроса.

[[info type=custom color=#E06823]]
Переход можно настроить только вперед: целевая страница должна находиться после текущей. Это исключает зацикливание сценария.
[[/info]]

Если для вопроса настроено несколько условий, система проверяет их сверху вниз и выполняет первое подходящее условие.

**При изменении структуры учитывайте следующее:**

- Если переместить целевую страницу перед текущей, переход станет недействительным и его потребуется настроить заново;
- Если сделать вопрос обязательным, условие `При пропуске` для него сбросится;
- При удалении страницы очищаются переходы на нее;
- При удалении вопроса удаляются связанные с ним условия.


## Шаг 4. Дизайн

Раздел **Дизайн** меняет только внешний вид веб-формы и не влияет на логику прохождения опроса. Форма автоматически подстраивается под мобильные устройства и компьютеры. Ширина контента определяется системой.

<!-- скриншот: настройки дизайна и превью опроса -->

[[delimiter rows=1]]

**Доступные настройки:**

- Цвет фона, полей, кнопок, акцентных элементов и текста;
- Логотип;
- Ссылка, направляющая при нажатии на логотип;
- Фоновое изображение;
- Затемнение фонового изображения.

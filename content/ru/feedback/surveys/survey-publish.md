После создания опрос сохраняется как черновик. Чтобы респонденты могли его пройти, опрос необходимо опубликовать.

После первой публикации система создает постоянную публичную ссылку и делает опрос доступным для подключения к рассылкам.

## Публикация опроса

Опубликовать можно опрос со статусом `Черновик` или `Снят с публикации`.

1. Откройте опрос.
2. Проверьте его структуру и настройки.
3. Укажите срок прохождения опроса (применяется для персональных ссылок, подробнее об этом ниже)
4. Нажмите `Опубликовать`.
5. Подтвердите публикацию в модальном окне.

При публикации система сохраняет текущие изменения и проверяет форму. При успешной публикации:

- Статус меняется на `Опубликован`;
- При первой публикации создается публичная ссылка;
- Опрос становится доступен для выбора в рассылках.

[[info type=custom color=#E06823]]
При повторной публикации новая публичная ссылка не создается. Система снова активирует ссылку, сформированную при первой публикации.
[[/info]]

## Публичная ссылка

Публичная ссылка предназначена для открытого прохождения опроса без привязки к конкретному гостю.

**Особенности:**

- Подходит для QR-кода, сайта, социальных сетей и других открытых каналов;
- По одной публичной ссылке можно отправлять ответы без ограничения по количеству прохождений;
- Если опрос снят с публикации или деактивирован, публичная ссылка становится недоступной для прохождения и копирования.

## Персональная ссылка

Персональная ссылка формируется для конкретного гостя при отправке опроса через рассылку. По ней система может связать полученный ответ с профилем гостя.

**Особенности:**

- Отправить ответ по одной ссылке можно только один раз;
- Ссылка имеет ограниченный срок действия.

### Срок прохождения опроса

Параметр **Срок прохождения опроса** определяет, сколько времени действует персональная ссылка с момента отправки сообщения.

[[info type=custom color=#E06823]]
По умолчанию используется **3 дня**. Если изменить срок прохождения, новое значение применяется ко всем персональным ссылкам этого опроса, включая уже отправленные.
[[/info]]

После истечения срока респондент увидит сообщение о недоступности опроса.

## Отправка опроса через рассылку

[[delimiter rows=1]]

Чтобы добавить опрос в сообщение рассылки:

1. Откройте создание или редактирование рассылки в разделе `Маркетинг -> Рассылки`.
2. На этапе `Контент` в текст сообщения добавьте переменную `Ссылка на опрос`.
3. В поле `Связанный опрос` выберите нужный опрос.
4. Сохраните настройки рассылки.

Поле `Связанный опрос` обязательно. В списке отображаются **только опубликованные опросы**.

При отправке система формирует персональную ссылку для каждого получателя.

Дополнительно система проверяет:

- Гость не должен быть отписан от рассылок опросов;
- Для автоматической рассылки с триггером `Закрытый чек` локация опроса должна совпадать с локацией заказа.

[[info type=custom color=#E06823]]
В текущей реализации локация ответа определяется автоматически только для ответов, полученных из автоматической рассылки с триггером `Закрытый чек`. Для остальных способов получения ответа поле локации может быть пустым.
[[/info]]

### Связанные рассылки

На вкладке **Распространение** отображается блок связанных рассылок. Для каждой рассылки показываются ее название и текущий статус. Это позволяет увидеть, где используется текущий опрос.

## Снятие опроса с публикации

Снять с публикации можно опрос со статусом `Опубликован`.

1. Откройте опубликованный опрос.
2. Нажмите `Снять с публикации`.
3. Подтвердите действие.

**После подтверждения:**

- Статус меняется на `Снят с публикации`;
- Публичная ссылка перестает работать;
- Опрос становится недоступен для новых подключений в рассылках;
- Активные рассылки, использующие этот опрос, переводятся в статус `Пауза`.

[[info type=custom color=#E06823]]
Снятие с публикации не сохраняет текущие несохраненные изменения формы. Сохраните изменения до выполнения этого действия.
[[/info]]

### Повторная публикация

Снятый с публикации опрос можно опубликовать снова. Повторная публикация аналогичная по шагам первичной. При этом используется прежняя публичная ссылка.

[[info type=custom color=#E06823]]
Связанные рассылки, ранее переведенные в статус `Пауза`, автоматически не возобновляются. Их необходимо активировать отдельно.
[[/info]]

## Деактивация опроса

Деактивация используется, если ранее опубликованный опрос больше не должен возвращаться в работу.

Деактивировать можно опрос со статусом `Опубликован` или `Снят с публикации`.

<!-- скриншот: блок Связанные рассылки на вкладке Распространение -->

[[delimiter rows=1]]

**После подтверждения:**

- Статус меняется на `Деактивирован`;
- Ссылки становятся недоступны;
- Опрос нельзя подключить к рассылке;
- Опрос открывается только в режиме просмотра, редактирование и повторная публикация недоступны.

[[info type=custom color=#E06823]]
Деактивация необратима. Для временной остановки используйте снятие с публикации.
[[/info]]

**Аккаунты** — это финансовые счета локации, по которым фиксируется движение денежных средств: поступления, расходы, перемещения и другие транзакции.

Аккаунты помогают разделять денежные потоки по типам счетов: банковские счета, банковские карты и наличные. У каждого аккаунта есть валюта, баланс и локация, к которой он относится.

[[info type=custom color=#E06823]]
При создании локации система автоматически создает набор дефолтных аккаунтов. Вы можете использовать их для основных финансовых операций или создать дополнительные аккаунты под структуру вашего бизнеса.
[[/info]]


### Аккаунты используются для учета денег в финансовом модуле

- При поступлении выручки

- При оплатах банковскими картами

- При учете наличных в кассе

- При перемещении наличных в сейф

- При учете наличных и безналичных чаевых

- При создании и просмотре транзакций.

## Типы аккаунтов

В системе доступны **три** типа аккаунтов.

### Bank Account / Банк. Аккаунт

Это банковский счет локации. Используется для хранения средств и проведения операций, которые проходят через банковскую систему. Для банковского счета можно указать процент эквайринга.

[[info type=custom color=#E06823]]
Если процент эквайринга заполнен, при поступлении средств система автоматически учитывает комиссию банка как расходную транзакцию по категории **Эквайринг**.
[[/info]]

### Bank Card / Банк. Карта

Это банковская карта. Используется для транзакций, которые проходят через карточные платежные системы: терминалы, онлайн-оплаты и другие карточные операции.

### Cash / Наличные

Используется для учета операций с физическими деньгами: наличная выручка, касса, сейф, наличные чаевые и другие операции с наличными.

## Список аккаунтов

В разделе **Финансы -> Аккаунты** отображается список аккаунтов выбранных локаций. В данном разделе можно просматривать, создавать, редактировать аккаунты, а также увидеть общую статистику по нескольким аккаунтам.

![account-info](/ru/images/accounts/accounts-info/accounts-info1.jpg)

### Колонки списка

- **Название** - Для дефолтных аккаунтов отображается плашка Назначения аккаунта. Для банковских аккаунтов с эквайрингом дополнительно отображается процент комиссии.
- **Локация**
- **Тип**
- **Баланс**
- **Дата открытия**
- **Комментарий** - Для деактивированных аккаунтов в этой колонке отображается причина деактивации.


## Поиск и фильтры

**Поиск выполняется по полям:**

- **Название**

- **Комментарий**

- **Причина** - Причина деактивации аккаунта.

**Доступные фильтры:**

![account-info](/ru/images/accounts/accounts-info/accounts-info5.jpg)

[[delimiter rows=1]]

- **Гео** - Фильтрует список по выбранным локациям. Должна быть выбрана хотя бы одна локация.

- **Статус** - Фильтрует аккаунты по статусу: Активный, Деактивированный или Все. По умолчанию выбран Активный.

- **Валюта** - Список валют формируется из валют, доступных пользователю локаций.

- **Статус по умолчанию** - Фильтрует аккаунты по признаку дефолтности.

- **Тип Аккаунта**

## Доступная статистика

В нижней части списка аккаунтов отображается агрегированная статистика по балансам аккаунтов.

Статистика помогает быстро оценить, сколько средств находится на аккаунтах выбранных локаций с учетом примененных фильтров.

## Дефолтные аккаунты

Дефолтные аккаунты создаются системой автоматически при создании новой локации. Они покрывают основные ежедневные финансовые потоки заведения. 

Дефолтные аккаунты помечаются специальным лейблом. Лейбл не меняется, даже если вы измените название аккаунта.

![account-info](/ru/images/accounts/accounts-info/accounts-info3.jpg)

[[delimiter rows=1]]

**В системе предусмотрены следующие назначения аккаунтов:**

- **Bank Account** — основной банковский счет локации

- **Cashbox** — счет кассы для наличной выручки

- **Safe** — счет сейфа для хранения наличных, перенесенных из кассы

- **Cash Tips** — счет для наличных чаевых

- **Non-Cash Tips** — счет для безналичных чаевых

[[info type=custom color=#E06823]]
Для каждого назначения всегда должен быть назначен один дефолтный аккаунт. Если вы устанавливаете назначение на новый дефолтный аккаунт, у предыдущего аккаунта этого типа признак дефолтности будет снят автоматически.
[[/info]]

### Назначение аккаунта дефолтным

Сделать аккаунт дефолтным можно только для пользовательских аккаунтов с типом **Банковский Аккаунт** или **Наличные**.

Для **Банковского Аккаунта** доступны назначения:

- **Банковский аккаунт**
- **Безналичные чаевые**

Для **Наличных** доступны назначения:

- **Касса**
- **Сейф**
- **Наличные чаевые**

![account-info](/ru/images/accounts/accounts-info/accounts-info4.jpg)

[[delimiter rows=1]]

**Чтобы назначить аккаунт дефолтным:**

**1.** Перейдите в раздел **Финансы -> Аккаунты**.

**2.** Создайте новый аккаунт (Или откройте редактирование уже ранее созданного вручную аккаунта).

**3.** В поле **Тип** выберите **Банк. Аккаунт** или **Наличные**.

**4.** Включите настройку **Аккаунт По Умолчанию**.

**5.** Выберите назначение аккаунта.

**6.** Нажмите **Сохранить**.

[[info type=custom color=#E06823]]
После сохранения выбранный аккаунт станет дефолтным. У предыдущего дефолтного аккаунта этого типа лейбл будет снят автоматически.
[[/info]]

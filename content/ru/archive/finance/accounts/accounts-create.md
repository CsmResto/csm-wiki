### Создание нового аккаунта

**1.** Перейдите в раздел **Финансы -> Аккаунты**.

**2.** Нажмите кнопку **Создать**.

![account-create](/ru/images/accounts/accounts-create/accounts-create1.jpg)

[[delimiter rows=1]]

**3.** Заполните поля формы:

- **Название**

- **Локация**

- **Дата открытия** — дата, начиная с которой аккаунт считается активным и может использоваться в транзакциях.

- **Валюта** — cписок доступных валют зависит от выбранной локации.

- **Тип** - Банковский Аккаунт/Наличные/Банковская Карта

- **Эквайринг** — размер комиссии эквайринга в процентах. Поле отображается только для типа `Банк. Аккаунт`.

- **Начальный баланс** — первоначальный баланс аккаунта. Укажите положительное или нулевое значение в выбранной валюте.

- **Аккаунт по умолчанию** — позволяет сделать аккаунт основным. Поле отображается только для типа `Банк. Аккаунт`.

- **Комментарий**

![account-create](/ru/images/accounts/accounts-create/accounts-create2.jpg)

[[delimiter rows=1]]

**4.** Нажмите **Создать**.

[[info type=custom color=#E06823]]
После сохранения аккаунт появится в списке и станет доступен для проведения транзакций с даты, указанной в поле **Дата открытия**.
[[/info]]

Импорт транзакций позволяет быстро загрузить большое количество операций с помощью CSV-файла без ручного ввода каждой записи.

Если данные выгружены из банка в другом формате, используйте [парсер выписок](/ru/finance/transactions/receipt-parser), чтобы подготовить файл для импорта.

### Импорт фактических транзакций

Используется для загрузки уже выполненных операций, например:

- банковских выписок
- доходов и расходов
- исторических финансовых данных

### Импорт плановых транзакций

Используется для загрузки ожидаемых операций, например:

- будущих платежей
- регулярных расходов
- планируемых поступлений

## Как работает импорт

![transactions-import](/ru/images/transactions/import/transactions-import.jpg)

[[delimiter]]

**1.** Выберите тип транзакций

Выберите вкладку:

- **Факт** — фактические транзакции
- **План** — плановые транзакции

**2.** Нажмите **Импорт**

![transactions-import-modal](/ru/images/transactions/import/transactions-import-modal.jpg)

[[delimiter]]

**3.** Выберите локацию, в которую будут импортированы транзакции.

**4.** Выберите аккаунт для импортируемых транзакций.
- доступны только аккаунты выбранной локации
- можно выбрать только один аккаунт

**5.** Загрузите CSV-файл размером до 30 MB.

**6.** Нажмите `Применить`.

[[info type=custom color=#E06823]]
После успешной проверки модальное окно закроется, появится уведомление об успешном импорте, а транзакции сразу отобразятся в списке.
[[/info]]

## Требования к CSV-файлу

### Общие правила

**1.** Используйте точку `.` как десятичный разделитель суммы.

**2.** Знак суммы определяет тип операции:

- `+` — доход
- `-` — расход

**3.** Одна категория может использоваться одновременно для доходных и расходных операций. Тип операции определяется знаком суммы.

**4.** Дата и время транзакций обрабатываются в таймзоне выбранной локации.

**5.** Дефолтные категории не могут быть использованы для импорта

## Поля CSV для фактических транзакций

| Поле | Описание |
|---|---|
| categoryId | ID категории |
| amount | Сумма транзакции |
| year | Год |
| month | Месяц |
| day | День |
| hour | Час *(необязательное поле)*|
| minute | Минуты *(необязательное поле)*|
| comment | Комментарий *(необязательное поле, до 250 символов)*|
| tags | Теги *(необязательное поле)*|

### Особенности

#### Время

Поля `hour` и `minute` можно не заполнять.

[[info type=custom color=#E06823]]
Если время отсутствует, система автоматически устанавливает значение `12:00`.
[[/info]]

#### Теги

- поле необязательное
- можно указать несколько тегов через запятую
- теги должны существовать для выбранной локации
- проверка чувствительна к регистру

### Пример CSV

```csv
year,month,day,hour,minute,categoryId,amount,comment,tags
2025,07,29,14,00,101,-1200.50,Аренда самокатов,
2025,07,29,09,10,102,18000,,IT,Salary
2026,07,30,,,103,-500000,Аренда помещения,
```

## Поля CSV для плановых транзакций

| Поле | Описание |
|---|---|
| categoryId | ID категории |
| plan_amount | Сумма плановой транзакции |
| year | Год |
| month | Месяц |
| day | День |
| comment | Комментарий *(необязательное поле)*|
| overdue_action | Действие при просрочке |
| tags | Теги *(необязательное поле)*|

#### Значения overdue_action

Поле определяет, что произойдет с транзакцией при просрочке. Используется только для `плановых транзакций`.

| Значение | Действие |
|---|---|
| 0 | Не переносить |
| 1 | Переносить на следующий календарный день до конца недели |
| 2 | Переносить на следующий календарный день до конца месяца |
| 3 | Переносить на следующий рабочий день до конца недели |
| 4 | Переносить на следующий рабочий день до конца месяца |

### Пример CSV

```csv
year,month,day,categoryId,plan_amount,comment,overdue_action,tags
2025,07,29,101,-1200.50,Аренда самокатов,0,
2025,07,29,102,18000,,1,IT,Salary
2026,07,30,103,-500000,Аренда помещения,4,
```

## Ошибки при импорте

| Ошибка | Описание |
|---|---|
| Ошибка при чтении файла | Система не смогла прочитать файл или обработать данные документа. |
| Файл пуст | Загруженный файл не содержит данных. |
| Файл содержит некорректные данные | В файле присутствуют неверные значения, некорректные форматы или отсутствуют обязательные поля. |
| Тип категории не соответствует знаку суммы | Тип категории не совпадает со знаком суммы. Например, расходная категория указана с положительной суммой. |
| Неизвестная категория | Указанный `categoryId` не существует в системе для выбранной локации. |
| Тег не существует для выбранной локации | В файле указан тег, отсутствующий для выбранной локации. |
| Категория недоступна для выбранной локации | Категория скрыта или недоступна для выбранной локации. |
| Дата транзакции не может быть в будущем | Дата фактической транзакции превышает текущую дату. *Проверяется только для фактических транзакций* |
| Структура файла не соответствует выбранному режиму импорта | Пользователь загрузил файл другого типа или в файле отсутствуют обязательные поля для выбранного режима импорта. |

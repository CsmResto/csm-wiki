**Транзакции** — это операции движения денежных средств в финансовом модуле. С их помощью вы фиксируете фактические поступления и списания, планируете будущие операции, связываете план с фактом и отслеживаете исполнение.

**Доступны два типа транзакций:**

- **Факт** — фактические транзакции, которые уже произошли.

- **План** — плановые транзакции, которые должны быть выполнены в будущем или к выбранной дате.

[[info type=custom color=#E06823]]
Плановую транзакцию можно связать с одной или несколькими фактическими транзакциями. Так система показывает, полностью или частично выполнен план.
[[/info]]

[[delimiter rows=1]]

## Типы транзакций

### Расход

**Расход** — расходная транзакция. Используется для фиксации списания средств: аренда, закупки, услуги, комиссии и другие расходы.

Для расходной транзакции выберите категорию с типом **Расход** или **Все**.

### Доход

**Доход** — доходная транзакция. Используется для фиксации поступления средств: выручка, возвраты, прочие доходы.

Для доходной транзакции выберите категорию с типом **Доход** или **Все**.

### Трансфер

**Трансфер** — перевод средств между аккаунтами. Для трансфера указываются два аккаунта:

- **Аккаунт от** — откуда списываются средства;
- **Аккаунт для** — куда поступают средства.

Если аккаунты в разных валютах, система отображает отдельные поля суммы для каждого аккаунта.

### Зарплата

**Зарплата** — зарплатная транзакция. Используется для учета выплат сотрудникам.

Для этого типа указывается сотрудник-получатель и отчетный период. Категория зарплаты задается системой автоматически.

[[info type=custom color=#E06823]]
В разделе **Финансы -> Категории** вы можете создать категории, которые используются для классификации транзакций и помогают вести более детальный финансовый учет помимо указания категорий.
[[/info]]

## Фильтры и поиск

Поиск производится по сумме, комментарию и причине деактивации.

Используйте фильтры, чтобы быстро найти нужные транзакции.

**Фильтры доступные для всех транзакций:**

- **Автор** — пользователь, создавший транзакцию;
- **Аккаунт** — аккаунт, по которому проводится транзакция;
- **Валюта** — валюта транзакции;
- **Дата деактивации** — дата деактивации транзакции;
- **Дата создания** — дата создания транзакции;
- **Документ** — наличие прикрепленного документа;
- **Категория** — категория транзакции;
- **Отчетная дата** - 
- **Получатель** — получатель средств или сотрудник для зарплатной транзакции;
- **Последнее изменение** — дата последнего изменения транзакции;
- **Статус** — состояние транзакции (активная или деактивированная);
- **Статус выполнения** — статус выполнения плановой транзакции;
- **Сумма** — сумма фактической транзакции;
- **Теги** — теги, назначенные транзакции;
- **Тип** — направление движения денежных средств;
- **Тип аккаунта** — тип аккаунта (банковский счет, банковская карта или наличные);

**Фильтры доступные также для плановых транзакций:**

- **Плановая сумма** — сумма плановой транзакции;
- **Фактическая сумма** — общая сумма прикрепленных фактических транзакций;
- **Связанная фактическая транзакция** — наличие связанной фактической транзакции у плановой транзакции.

[[info type=custom color=#E06823]]
Фильтр **Сумма** применяется только к фактическим транзакциям. Фильтры **Плановая сумма**, **Фактическая сумма** и **Связанная факт. транзакция** применяются только к плановым транзакциям.
[[/info]]

## Статистика в нижней панели

В нижней панели списка отображаются агрегированные показатели по транзакциям, которые сейчас видны в таблице.
Панель обновляется автоматически при изменении списка, фильтров или поискового запроса. Если список пуст или фильтры не нашли транзакции, нижняя панель не отображается.

![Статистика](/ru/images/transactions/transactions-info/transactions-info3.jpg)

[[delimiter rows=1]]

**Панель может показывать:**

- **Доход** — сумма доходных транзакций;
- **Затраты** — сумма расходных транзакций;
- **Входящие трансферы** — сумма входящих трансферов;
- **Исходящие трансферы** — сумма исходящих трансферов;
- **Всего** — итоговая сумма по отображаемым транзакциям.

[[info type=custom color=#E06823]]
На вкладке плановых транзакций сравнивается сумма плановых транзакций **со связанными с ними фактическими транзакциями**.
[[/info]]



[[info type=custom color=#E06823]]
Если в списке есть транзакции в разных валютах, в панели отображается переключатель валют. **Переключатель меняет валюту отображения данных, но не конвертирует суммы.**
[[/info]]
